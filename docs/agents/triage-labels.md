# Triage Labels

工程 Skills 使用五种标准分流角色。此文件将这些角色映射到本仓库 Issue tracker 中的实际标签名称。

| mattpocock/skills 中的角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估此 Issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可以交给 Agent 独立处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现或决策 |
| `wontfix` | `wontfix` | 已决定不处理 |

当 Skill 提到某种分流角色时，应使用表中对应的实际标签名称。

如果仓库以后改用其他标签词汇，只需修改表格的“本仓库标签”列。
