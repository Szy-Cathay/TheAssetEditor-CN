# 模组操作助手

从工具入口打开助手，通过右上角设置或应用设置保存自己的 DeepSeek API Key。在资源树或编辑器选好目标后输入任务，点击发送或按 Ctrl+Enter；Enter 保留换行，输入法选字不会触发发送。顶部显示当前工程和编辑器，点击可查看附加内容与未保存状态；切换到助手页不丢失任务目标。

界面参考官方 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness/tree/master/packages/client/ui-chat) 的会话、消息流、执行过程和底部输入区结构，以原生 WPF 实现。宽工作区显示可收起的最近会话；窄工作区通过左上角菜单进入会话列表，保留输入区宽度。新建会话不清除旧会话，切换保留各自的模型上下文、草稿、图片与用量；执行期间禁止切换会话。思考过程和工具执行按实际发生顺序插入消息，工具从正在执行更新为真实结果，失败原因直接显示。展开记录可查看目标、前后标量变化、原始参数与结果，并在条件允许时定位、撤销或重做。回答支持选择、复制及 Markdown 排版；工具结果里的原始内容默认收起。向上阅读时新回复不会强行滚回底部，可点击“回到最新消息”。

输入区提供深度思考、联网搜索、图片附件以及发送／停止按钮。图片在发送前和用户消息中保留预览；附件菜单可选择文件或粘贴剪贴板图片。设置、上下文位于次级页面，返回后保留对话与草稿。预设任务只填入输入框，不会自动执行。开始执行不代表保存成功，停止也不会撤回已完成修改。

回复按标题、正文、列表和表格分层显示，限制行宽并保持左对齐；代码块跟随主题并自动换行。鼠标停在回复上可直接滚动整段对话；展开的思考／操作详情先滚动自身，到边缘后继续滚动对话。用量与该轮目标／保存摘要收在回答下方“详情”中；界面保留正在执行、失败及可采取动作的提示，不常驻显示模型标语或泛泛结束提示。普通能力问题要求简短介绍和示例，不自动发起资源自测；内部参数和诊断留在展开记录中。

操作能力由当前游戏、工程、文档及资源决定。下表区分实现范围与验证边界；注册操作不等于所有游戏和素材都已验收。

## 本轮补齐的操作边界

- 高级音频参数包括容器类型、随机模式、避免重复及间隔、序列结尾行为、重置播放列表、逐步／连续播放、循环类型与次数、过渡类型与秒数。局部补丁先检查整个批次，参数是否可用遵守原生设置面板的模式条件。准备设置只影响下一次添加；修改已有对象进入未保存状态，可按组撤销／重做。
- 工程历史恢复先查询并绑定明确目录，只有现有历史服务判定可以恢复时才启用。删除还原点保留磁盘文件，不能删除初始还原点；放弃指定改动不改变其他文件；放弃全部改动需明确当前工程目录，沿用完整工程关闭／重载流程。异常恢复保留当前磁盘内容并重新打开工程。源码仓库的 Git 操作仍需另外授权。
- 报告每次最多 100 个指定资源，单文件 32 MiB、合计 64 MiB；材质引用额外最多 100 项并计入总字节限制。输出必须是工程外的新目录，最大 2048 个文件、128 MiB。结果列出实际输入、依赖、输出散列及诊断；中断保留已写出的文件并如实报告。
- 报告沿用现有解析范围：RMV2 的加权材质明细模板目前没有数据采集实现；动画包仅 WH3 动画表可导出 XML；音频报告按明确选择的 BNK 与可选 DAT 解析，缺少名称时保留数字 ID，不自动加载全部语言音频库。`init.bnk`、未知 BNK 版本／HIRC 项返回限制或诊断。深度搜索沿用 ASCII 内容搜索。文件清单的独立 CSV 比较辅助函数不是当前菜单入口，未新增为助手命令。

## 数据发送、费用与恢复

- 发送对话、当前工程与标签摘要、任务所需工具结果和主动附加的图片；不会自动上传整个工程／游戏库，也不会自动截图。上下文页可查看摘要，图片可预览／移除，上限 4 MiB、4096 × 4096。
- Key 使用 Windows 当前用户加密，保存在 AECN 独立本地应用目录的 `Assistant/key.dpapi`，不进入普通配置或日志。账户变化或重装系统后可能需要重新输入。无 Key 或断网不影响普通 AECN 编辑器。
- 会话只在本工具页内存中保存，关闭工具页后清除；不自动写入聊天记录。“新建会话”使用独立模型上下文，旧会话仍可继续。每轮回答可查看接口返回的累计用量，费用以服务商账单为准，不编造精确价格。
- 模型回答中的图片语法按原文显示，渲染器不会自动读取远程或本地图片；用户主动附加的图片使用独立预览。Markdown 不启用 HTML 扩展，链接只允许用户主动打开 HTTP／HTTPS 网页，不运行文件、脚本或命令。
- 内存编辑默认不保存；编辑器未保存内容、工程磁盘、Git、输出 Pack 分开。原生撤销优先，适配器快照历史会检查中途改动，避免覆盖用户后续工作。
- 磁盘操作沿用工程事务、备份、历史和冲突对话框，没有统一磁盘撤销承诺。外部导出使用新路径。模型转换暂存副本保留于本地应用目录 `Assistant/exports/`，成功结果报告具体路径。
- “停止”取消请求与后续步骤；已经完成的修改不会自动消失。同步原生工作在可检查点停止，以实际结果和当前保存状态为准。
- 删除、历史还原显示具体目标确认；路径选择和覆盖冲突沿用现有对话框。范围清楚的普通编辑直接执行。不从网页或资源文字推导操作授权，不提供任意代码、Shell、无约束反射、通用鼠标键盘执行或对外发布。

## 执行与扩展

协议在 `Shared/SharedCore/ModAssistant`，应用上下文与 UI 在 `AssetEditor/ModAssistant`。各模块通过自身 DI 提供编辑器、资源或工作区适配，复用所属命令。操作说明包含稳定目标、参数类型／范围／单位、影响、恢复方式、适用范围和当前不可用原因。

本地检查参数、游戏、目标身份、修订和只读规则；用户等待期间切换工程／游戏或修改相关数据，会重新检查或拒绝后续操作。读取使用分页和限额。一轮最多 24 次模型交互、48 次本地执行，同一操作／目标连续失败达到 3 次后停止重复尝试。网络和工具有截止时间，同步原生工作不强行中止。调用与修改指纹防止重复执行；部分完成和执行后无法核实分别报告。

UI 沿用原生 WPF、AECN 主题、中文资源、公共按钮／输入／列表／折叠样式和长操作进度组件；Markdown 复用更新说明已使用的 MdXaml。未增加公共 UI 组件。依照用户指定 Modern Web Guidance 中适用的 accessibility 原则，保留持久输入标签、原生交互语义、图标按钮名称、键盘焦点、附件说明和完成通知；不逐字播报流式输出。网页专属 DOM／CSS 不引入 WPF。

## 验证记录

相关自动化、原生解析／服务回归、WPF 离屏与 GPU 离屏分别执行，阶段日志和 TRX 位于本轮 `artifacts/mod-assistant/`。离屏不能代替真实窗口、键盘／读屏或游戏验收；未配置真实 Key 时，模拟模型通过不能写成 DeepSeek 实测通过。长期说明不固定测试数量，交付报告列出本轮实际结果。
