# VFX 编辑、实时预览与验证

## 何时读取

适用于 VFX XML 编辑器、Effekseer 场内预览、游戏特效语义转换、共享特效节点及其验证。先读“硬边界”“修改路由”“验证门禁”，再按任务读取下列具体语义；涉及多个渲染环节时同时检查相关段落，不能只依据一条支持说明。

本文记录现有实现的稳定契约和已知限制。源码与测试是当前事实来源；历史修复过程、样本覆盖、人工反馈及本轮未完成事项见仓库根的 [HANDOFF-VFX-LOCAL.md](../HANDOFF-VFX-LOCAL.md)。UI 样式以 [UI 设计系统](ui-design-system.md) 为准，超级视图的 META 所有权与编辑以 [superview.md](superview.md) 为准。

## 硬边界

- 新增窗口、离屏、Terry 对照和视觉验收只使用官方原版特效及其原始模型、贴图和依赖。先从游戏 manifest 指定的官方 Pack 核对实际资源来源，排除已加载 Mod 的同名覆盖；既有 Mod 记录仅作历史。单变量诊断须保留官方原件并标记改动，最终仍回到未经修改的完整原版效果。

- 原始游戏 XML 是编辑与保存的权威来源；预览转换、范围选择、挂点拖动、画质和连续 trail 策略都不能暗中改写源数据。未知字段与未经编辑的曲线元数据继续保留。
- 普通面片的 GPU 规则与模型粒子的 CPU 规则分别核实。当前能绘制、移除了“不支持”判断或增加了测试数量，都不等于原生语义和完整外观已经正确；不得为某个特效名称单独调参掩盖共用问题。
- 全局模拟步长保持 `1.0 / 120`。优先修复几何、方向、透明度、材质和运动；明显材质错误未解决前，不用泛光、曝光、延长粒子寿命或其他能力扩展掩盖差异。
- 构建、桌面输入、用户人工验收与 Git 操作分别遵守根 [AGENTS.md](../AGENTS.md)。用户选择自行实机测试时，完成已授权的源码、参数和离屏验证并交付正常 Debug；未做的 AECN、Terry 或游戏验收必须保留待验状态。

## 已实现语义及限制

以下条目描述各自受限组合，不是支持所有参数的清单。某个完整特效可能同时包含已支持、候选近似及被诊断停用的层；应先读取该层诊断，再定位发射、材质或合成环节。

### 文档编辑与保存

- `Editors/VfxEditor` 编辑 `vfx/` 下 revision 1/2 的 XML 片段，组合根通过该模块的 `DependencyInjectionContainer` 注册。原有文本编辑器仍可选用；XML 格式错误显示文件名和行列位置，不自动修补源文件。

- `Shared/GameFiles/Vfx` 保留文件编码、顶层节点、未知数据和未修改的曲线元数据；未编辑时写回原始字节。曲线按时间显示，写回保留原始关键点顺序及同时间点；只调整已有关键点的时间和值，非线性段显示关键点连线示意，不模拟游戏插值或特效渲染。

- 编辑器中间为常驻场景与公共播放器，右侧按参数、效果层和诊断分类，复用主窗口左侧资源树；文件、编辑和视图操作放在场景顶部紧凑菜单。参数使用中文术语，原始字段名、用途、调整方法和限制放入悬停提示；未知字段显示原始名并在提示中保留未确认语义的说明，不提供猜测性调法。搜索覆盖当前层所有分类，仍遵守画质筛选；中文名称来自 `Language_Cn.json`，模式选择写回原始游戏值。曲线横轴保留源文件刻度，不统一换算时间单位。

- 发射器、同名行为链和渲染栈合并展示为效果层；引用与引用层覆盖单独编辑，画质档位独立。新建组合使用原生 `vfx_references`，依赖源 VFX 及其资源；位置、旋转、大小和开始时间成组编辑。复制或移除层同步处理关联行为链、渲染栈和编辑器元数据，结构撤销保留节点身份，兼容已有字段撤销；不增删曲线关键点。

- 保存走 `IFileSaveService`：当前工程内的文件按所属容器定位，参考资源或其他工程资源另存；文件已被外部修改、输入无效、保存失败或取消时保留未保存状态。

- 打开 VFX 后直接进入三维编辑预览，使用当前页内存快照；依赖按源工程、当前工程、已加载参考和原版资源解析，不保存文档或改变撤销状态。场景下方复用 `AnimationPlayerView` 的秒数模式，由 `VfxPlaybackViewModel` 适配播放、暂停、循环和拖动；特效没有骨骼动画帧率，不显示虚构的帧数或逐帧按钮。

- 效果层的勾选与“仅查看此层”只改变当前场景的预览范围，支持单独或组合查看；编辑层选择、属性画质筛选和预览画质不暗改这个范围。`VfxPreviewRootSelection` 分开发射器 ID 与引用实例名，只筛选顶层，未选根不加载其资源，已选根的递归引用和事件依赖继续保留。空选择不显示任何根层；全选恢复原始完整范围。此状态不写入源 XML、撤销栈、保存状态或供共享场景消费的快照。

- 初次打开时，`construction_type=2` 的组合与仅有一个可预览根层的文件默认显示完整范围；其余多根文件先显示选择提示，等待用户勾选，也可一键全选。该规则是界面的明确默认范围，不是通用的特效库识别，不按文件名猜测库或独立完整效果。

### 共享预览与原生桥

- 场内预览仍使用候选游戏语义适配。`GameWorld/View3D/Vfx/IVfxPreview` 接收当前游戏文档字节、资源解析器、画质、时间和调用者提供的骨骼/根世界变换；独立编辑器使用 `VfxPreviewComponent`，共享场景使用 `VfxPreviewSceneNode`，都在普通表面之后绘制，不注册模型选择、覆盖层或 Kitbash 工具。编辑器通过 `VfxPreviewDocumentStore` 按实际文件引用发布未筛选根层的未保存快照，即使本页预览范围为空也供其他场景消费；无效内容发布无效状态，不能继续展示旧保存内容。重载以 300 毫秒合并连续修改，调度优先于持续渲染，避免多个预览开启时一直等待渲染空闲。刷新不保存文件、不改变撤销历史；关闭编辑器移除快照，关闭场景释放运行时实例和订阅。

- 独立 VFX 场景与超级视图显式启用既有 `D3D11Host` 的 `SuspendWhenHidden`，其他编辑器默认不启用。外层缓存标签隐藏时，暂停该场景的更新、绘制及 GPU 呈现等待；不销毁实例、重载资源、重置模拟或改写播放／暂停开关。切回保留当前模拟与播放器位置，首帧使用零增量重绘，不追算隐藏时段；尺寸、DPI 及前缓冲恢复继续沿用原资源重建条件，不因普通切页重建目标。该策略不修改既有绝对 `GameTime.TotalGameTime` 材质时钟，使用该时钟的普通模型材质和环境动画恢复时仍取当前相位，不能称为所有着色器的全局暂停。

- 普通场景通过 `BeginScene`、`DrawInScene` 与 `EndScene` 显式共享一次 VFX 合成作用域；提交时复制粒子、摄像机矩阵及光照，并持有预览资源和独立柔边深度视图，直到组内绘制结束。全部实例的不透明 VFX 模型先写入场景深度，再提交普通颜色，随后进行全组扭曲方向与全组透射率两遍累积；有扭曲贡献时只解析一次背景。8 位显示目标中的各实例共用同尺寸、同采样数的浮点颜色目标，合成结束后统一执行一次泛光与显示输出。临时目标使用期间解绑调用者的输出 UAV，结束或异常退出时恢复 RTV、深度附件、UAV 及其附加计数器。此规则限显式作用域路线；未提供作用域的 `Draw` 保留单次调用内的颜色与扭曲合成兼容路径，不自动跨调用分组，也不代表所有材质、透明通道与游戏后处理均已还原。

- 显式 `FULLRES_DEFERRED_ALPHA`／`HALFRES_DEFERRED_ALPHA` 的普通有贴图面片在整组准入时使用原生七矩透明累积。原始浮点 RGBA、原粒子变换矩阵、图集及原材质倍率分别传入，不先拆成两个独立原生图元。先累计所有实例的七个矩，再把半分辨率的全部七矩按整数 2 倍坐标加进全分辨率矩池；全、半分辨率颜色分别以坐标倍率 1／2 读取同一矩池。最后以全局透射率 `T=exp(-B0)` 和原生权重重建合并颜色，半尺寸颜色使用原生 nofilter 的线性上采样，场景显示输出仍只处理一次。新通道按兼容的材质、光照、纹理、深度及分辨率稳定分组，旧兼容通道的逐粒子覆盖／发光顺序不变。
- 原生透明通道的半尺寸硬件深度和需要柔边时的四分之一尺寸深度，按需由本帧完整深度顺次生成：每级对原 2×2 深度取 `max(0,z00,z10,z01,z11)`，分配尺寸向下取整，不对不完整奇数边缘补点。硬件遮挡使用半尺寸 D24S8，柔边使用另一级视图，不能互相替代。普通 Debug 的 4 倍抗锯齿保留：全尺寸矩与颜色逐采样绘制并使用原 4 倍深度，半尺寸颜色读取全矩的采样平均值；现有完整深度的 MSAA 最小值解析保持独立。原生规则依据单采样记录，4 倍桥接是 AECN 的兼容实现，不能写成已核实的游戏 MSAA 规则。
- 新透明通道的 diffuse／normal 保留原始全部 mip，通过硬件三线性采样和边界 Clamp 读取；矩场使用整数读取。AECN 最终 RGB 使用与原生等价的透射混合，场景 Alpha 取既有 Alpha 与有效覆盖率 `1-T` 的最大值；原生参考目标的 Alpha 写零是独立显示目标约定，不能据此清空 AECN 场景 Alpha。
- 新透明通道只在整组颜色粒子均为已配置的显式全／半分辨率普通面片、无模型／贴花／扭曲／渐变／专用材质、同摄像机的透视与零起点视口、支持的单采样或 4 倍 RGBA16F 目标时准入。未显式声明的通道、正交或偏移视口、其他目标与混合未准入层保留完整旧覆盖／发光图层及倍率回退；不为了进入新通道降低画质或删层。有限原生输入和离屏控制不等于所有完整效果或所有相机阶段已验收。


- 原生桥固定使用官方 Effekseer `170e` 源码；`GameWorld/Vfx.Effekseer.Native/Build.ps1` 校验源码提交并单独构建，再由正常的 .NET 输出复制 DLL 与许可证。固定候选材质由同一版本编译器在原生构建时编译并嵌入 DLL，运行时直接加载，材质源变化会重新生成，不依赖用户机器上的外置编译缓存。桥接只使用核心及 DX11 renderer，复用 MonoGame 的设备和上下文，不引入另一套图形栈。贴图沿用 AECN 的 `ImageLoader` / Pfim 解码（包括 BC7），漫反射按游戏 `ps_texture` 以 sRGB 采样（包括无 DX10 色彩标记的旧 DDS），材质数值用途保留 DDS DX10 的显式 sRGB 格式，无标记旧 DDS 与显式线性格式仍按线性采样；扭曲法线保持线性采样，再上传像素；同一次重新加载中，字节与用途完全一致的贴图只解码和上传一次，各逻辑槽位保留，漫反射、数值及法线用途不混用。资源改变后重新加载会重新核对内容，不沿用旧快照的纹理。上传原贴图自带的完整缩小层，不重新生成或修改 DDS；Pfim 小尺寸压缩层的块填充不作为实际像素上传。共用自定义材质使用同一固定版本的着色器生成器，并通过标准 DX11 编译器补上相邻原始层的线性混合，保留原有纹理寻址及色彩空间；普通 Effekseer 回退通道仍选择最近层。常量透明度优化必须检查全部已上传层，避免丢弃低分辨率层的覆盖或发光。打包遮罩图集仍使用最高层，半分辨率与深度合成需要独立验证。普通 .NET 构建不自动联网下载或编译原生依赖；缺失或 ABI 不符时给出预览诊断。 CI 在托管构建前显式取得同一固定提交并构建 Release 原生桥，构建后核对主程序输出中的 DLL 与两份许可证；不依赖开发机已有产物。

- FloatScene 场景合成的八份着色器统一取自 `FloatSceneShaderSources.h`；MSAA 深度解析和加权折射的三份辅助程序取自 `SceneUtilityShaderSources.h`。它们由 `CompileSceneShaders.cpp` 在原生构建期沿用原入口、`vs_5_0`／`ps_5_0`／`cs_5_0` profile 和编译 flags 生成内置字节码，再嵌入 DLL。生成头记录每份展开后的 HLSL 源码散列、profile 与 flags；CMake 显式串联源码、生成器、生成头及桥接的依赖，相关源变化时重新生成。运行时直接使用内置字节码创建 DX11 着色器，不在资源加载或首次绘制时编译，也不读取外置着色器缓存。该优化保留原着色器功能、采样与画质，不调整粒子数量或模拟步长；资源首次转换、贴图解码与上传仍有各自的加载成本。

- 每个播放实例复用自己的托管提交列表与容量数组，只把本帧有效数量交给原生桥；调用者取得的粒子快照仍独立。原生普通固定颜色面片把相邻且兼容的段合批，原 Effekseer 固定四角、字节颜色量化和覆盖／发光原始图元次序保留。四组逐面片动态 uniform 随顶点传递且不插值，其余十一组常量、纹理、采样、深度及布局必须逐位一致才共段。RGB 批使用第二源透明度分别保留覆盖与发光的衰减，再以同序 Alpha-only MAX 批保留目标透明度；原半精度 RGB 写入次数与顺序不折叠。这不是游戏的 MBOIT，也未补齐半分辨率重建。模型、贴花、折射或不兼容状态先提交当前段，再走原入口；短段、不支持的目标或设备回放原标准队列。材质模板、资源及着色器绑定缓存限当前绘制作用域，结束、重配、异常与回退时在队列安全入口失效并恢复外部 DX11 状态。合批不调整排序、粒子数量、寿命、贴图或画质，具体收益仍需完整原版特效的独立计时和普通窗口验证。

- 原生桥对无顶点位移的普通颜色面片提供保守视野剔除：仅仿射观察矩阵、实际未绑定几何着色器及既有普通自定义材质准入；按真实轴心、局部反射和固定四边形变换检查四角。整批每个面片的四角均明确越过该面片的同一屏幕侧边时，才省去该批绘制；穿边、近裁面、非有限值或数值不确定的情况保留原绘制与校验，不用中心点直接拒绝。全览的少量原点检查只可关闭本次剔除，不可据此删除粒子。模拟、粒子数量、寿命、原批内颜色量化和剩余覆盖／发光次序不变；模型、投影贴花与折射不走此分支。收益取决于实际画面外的面片比例，不能据此宣称默认全览或所有场景已经稳定流畅。

### 画质、曲线与字段解释

- 渲染通道 `scene_view_type` 按原文件默认档位与当前预览画质合并后，取当前档位的覆盖值；不能因先读到默认通道而丢弃其他档位有效的面片。原生对照仍须核实画质，半分辨率与完整透明合成的限制不因此消除。

- 场内“预览画质”独立选择整个特效及递归引用使用的原文件档位（0、1、2，默认 0）；参数区的画质筛选及层选择只影响编辑字段，不再暗中改变预览。预览选择不改原始数据、撤销栈或保存状态，不自动修改 Terry 的全局设置。不同档位可能有不同数量、寿命及材质参数；原生对照须确认实际档位，不能把档位差异当成发射或材质故障，也不能假定文件编号在所有游戏与设置中对应相同画质名称。

- 游戏语义由托管转换与固定步长模拟负责，Effekseer 的公开 sprite/model renderer 接收逐粒子绘制数据，不要求游戏格式先保存为 Effekseer 格式。转换覆盖普通面片、受支持材质的静态模型、随机上下界曲线、负开始时间预热、发射数量上限、初始大小/透明度、局部与世界空间、图集格序和相邻帧混合，以及静态引用组合的时间、变换和颜色覆盖。预览转换把曲线解析为独立、只读的数值快照，播放取样不反复解析可编辑格式的字符串；依赖编辑仍通过现有快照重载生效，原始通道、关键点和插值算法保持。常用 `exp1`、`exp3`、`log1`、`log3`、`sine`、`sine_recip`、`s` 与 `linear` 的端点组合有 Terry 尺寸对照，按段内归一化时间混合两端函数，支持下降、非整段时间和多关键帧；保留原始通道与数据。同一颜色曲线的 RGB 与亮度、寿命内尺寸曲线的各轴按原生着色器的单一随机权重取值，保留出生时原有随机数消耗顺序；随机种子及未列明的预烘焙曲线纹理仍未与游戏同步。同时间同值的关键点在预览快照中保留第一个入切线和最后一个出切线，原文件不改写；同时间异值仍严格停用该层，不以容差合并。普通面片尺寸的空 Z 通道在快照中按 1 处理，有效 Z 保留用于事件继承；模型、投影贴花和其他字段仍要求有效的三维通道。`bezier_c` 与上述非线性解析模式的混合，先按存储切线求三次贝塞尔值，再按段内归一化时间混合两端函数；固定深度的上升、下降和非对称切线控制支持这一受限规则，除下述普通面片尺寸的受限 `bezier_q` 分支外，其他未校准 Bezier 类型及 `step_next`、`s_inv` 等模式仍停用受影响层。已有线性/Bezier 与纯 Bezier 路径保持，其他存储切线仍按候选采样；必要通道缺失、递归引用或缺失资源也会明确诊断。曲线尺寸对照不证明模型材质、透明合成或其他字段的时间语义完整保真。初速度方向、未覆盖的 Bezier 切线含义、材质混合及引用时间等仍是待原生对照的候选解释。

- 普通面片的平面 `ParticleScale` 只有在相邻关键点的出／入端存在实际 `bezier_q` 段时，才进入独立原生尺寸表分支。输入严格为 `x_min/x_max/y_min/y_max/z_min/z_max` 六个实存通道，XYZ 绑定分别为原始索引 `0/1`、`2/3`、`4/5`；各轴 split=0 只接受量化后完全相同的上下表，split=1 可保留不同上下界，不推断缺失通道或重排绑定。涉及 q 的端点组合仅支持 `linear→bezier_q`、`bezier_q→linear`、`bezier_q→bezier_q`、`bezier_q→sine_recip`（原生 0→11、11→0、11→11、11→8）。无论 q 在出端还是入端，都取左关键点的 outgoing 作为唯一控制点，按 float `0.6667` 转成两个三次控制点，再沿用原生十次二分及后续扫描；不套通用三次 Bezier 的双切线解释。`exp1` 与 q 的未验证混合、未知模式和非法控制仍诊断；模型、`ParticleInitialScale`、颜色／透明度等其他字段不因本分支开放 q 插值。

- 该尺寸分支按 `float(i)/128` 烘焙并使用原生有符号 half 量化，保留最小 XYZ（raw 0/2/4）与最大 XYZ（raw 1/3/5）两行；这对应原生尺寸常量纹理的第 6/7 行，不使用模型的 `i/127` 表。寿命阶段与同一粒子随机权重共同决定 XYZ 的双表取值，预览使用归一化线性／Clamp 的便携双线性几何。原始有效 Z 不改写，平面绘制仍固定局部 Z 尺度为 1。精确烘焙及 half 位值不代表固定功能纹理过滤逐位等价：不同 GPU 的子纹素权重与过滤输出舍入可能不同，当前硬件观察及误差范围须单独记录；尺寸数值与静态尺寸像素对照不能代替完整原版特效的视觉验收。

- 预览参数按所属行为片段解析，`vs_colour`、`vs_vertex_alpha` 与 `ps_gradient` 的同名曲线保持独立；同一片段内的重复参数仍诊断。`ps_gradient` 通过预览查找表映射过滤后的贴图红色及可选透明度，再乘独立粒子颜色；不把渐变解释为粒子年龄。查找表量化、随机渐变和游戏预烘焙纹理精度仍有差异。普通面片的原生数量/尺寸对照支持缺省发射率 10 个/秒、粒子寿命 1 秒、粒子大小 1，以及旧版尺寸曲线中未填写的 Y/Z 保留默认值 1；不把 X 复制到其他轴。省略发射器寿命的恒定发射对照支持持续预览，确切结束时刻及动态发射器曲线归一化仍为候选。发射器旋转默认只影响发射方向，不直接加入粒子自身旋转；显式相对旋转仍按候选处理。引用的 `infinite_life=false` 在子层明确填写寿命时限制其发射区间，`true` 不会把本来有限的子层改为无限；随机、嵌套时序的完整语义仍待对照。普通面片缺省 `ParticleSimulationSpace` 按 `WORLD_SPACE` 留在出生位置；显式 `LOCAL_SPACE_POSITION_ONLY` 与 `LOCAL_SPACE_POSITION_ROTATION` 保留各自跟随行为。移动事件发射器的缺省／世界／两种本地空间并排原生对照支持该默认值，不能据此外推刚体缺省、复杂挂点或继承速度。所有兼容默认值只用于预览，不补写原文件。

### 引用与粒子事件

- 静态引用的 `emitter` 列表用于选择直接子发射器，未列出的直接子层不参与转换、模拟或初始取景；空列表不播放直接子层，根文档选择完整预览范围时，仍按自身启用状态预览；编辑器的顶层预览范围另行应用。引用的 `enable=true` 不能重新启用源层的 `Enable=false`，两个开关均须允许播放；源开关仍按选定画质解析。列表选择有同位置 Terry 红绿双层、单选与空列表对照，源开关另有同一原始模型材质的启用／停用并排对照。嵌套引用的完整选择传播规则仍待校准，不推定已覆盖。

- `continuous_rigid` 的 `OnParticleSpawn`、`OnParticleDeath` 在显式 `EventEnable=true` 时实例化子特效；无模型、但具有这些事件字段的父层只参与模拟，不补造模型或纹理。子定义只作为事件模板上传，不自动发射，也不计入源层映射数量。出生的正时间偏移延迟触发、负值按零处理；死亡事件使用死亡时刻。尺寸、颜色、透明度跟随及寿命跟随的停止发射规则有受控 Terry 对照；父粒子结束后保留已出生子粒子的尾段并冻结继承挂点，重播周期包含子尾段。可见刚体模型的事件位置通常使用出生点及可选外部挂点跟随；进入下述受限原生 FullLocal 动态位置路径时，改为采样父模型实际位置，按事件设置继承其原生姿态。无模型事件辅助粒子仍沿自身运动更新挂点。非零初速度的出生偏移、速度朝向、复杂运动、引用时间倍率与完整外观仍为候选。普通面片原生控制未触发事件，其绘制保留并诊断。动态事件实例上限为 4096，仍共用全局 65536 粒子预算和原固定步长；缺失子资源或真正递归只诊断受影响事件，其他已转换层保留。事件可回到同一库并选择其他层，递归检查区分启用选择；资源读取沿用现有快照依赖追踪。Terry 导出递归收集启用事件的私有依赖，仅改写临时别名，并允许经过事件边回到已分配别名的库，纯静态引用循环仍拒绝；导出不修改源文档。水平地形事件沿用显式接收面和变换限制；共享节点默认不提供地面，超级视图明确使用现有网格的世界 Y=0 接收面。

### 播放、选择与连续 trail

- VFX 专属 `VfxEmitterInteractionComponent` 复用共享 `Gizmo` 的 Blender 变换和鼠标所有权，只操纵当前预览范围的共同挂点，单层预览即该发射器。选择、直接拖动、G/R/S、轴约束、数值输入与确认／取消均为临时预览，不写 XML、不改变文档版本和 dirty，不启用模型选择或 Kitbash 专属组件。VFX 不绘制变换文字、约束线或轴柄，也不显示顶部“发射器”菜单；在共同挂点持续绘制小型空心方块线框，未选中为灰色、选中为黄色，按相机投影保持较小的屏幕尺寸，不随特效范围、挂点缩放或拖尾长度扩大。点击效果估算边界或原点选择，再次命中已选效果可直接自由拖动；点击空白取消选择并保留灰色线框；从空白处按住左键拖框，与小方块投影边界相交时在松开后选中，四个拖动方向均有效。框选期间持有鼠标所有权，不开启连续变换或光标环绕；Esc、右键或捕获中断取消框选并恢复此前选择，正常松开后释放所有权。确认后的平移／旋转／缩放与重置按一次操作记录，和参数编辑共享当前页的撤销／重做顺序；取消或没有变化不入栈。Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做；正在变换或框选时 Ctrl+Z 先取消当前操作。预览项只恢复挂点，不重建文档、重载预览或修改保存点；新操作清除重做分支，成功加载另一文档时清空本页历史。恢复挂点在当前时间记录一次变换，保留过去的世界空间出生轨迹及粒子寿命，不回拨时钟或倒放整条 trail；回看后恢复按当前时刻分支并截去未来挂点轨迹。隐藏轴柄不参与命中，共享 Gizmo 绘制和 Kitbash 表现保持独立。挂点轨迹通过 `VfxPreviewComponent` 的可选历史采样传给既有固定步长模拟；世界空间粒子保留出生挂点，局部空间依原文件跟随。原两参播放及三参历史取样协议保持不变；只有 VFX 编辑器通过四参调用显式区分当前显示挂点与历史出生挂点。运行时桌面拖动、完整官方 trail 外观和线框的实际操作观感需单独实机验收。

- 独立编辑器按实际帧间隔推进本轮播放的绝对时间，再交给原固定 `1/120` 模拟；低帧率下不截断每帧时间使动画变慢。普通效果的显式末端定位保留该帧，自然到尾按循环设置重播或暂停。收起播放器暂停，展开恢复此前播放意图，不销毁预览。

- 独立编辑器通过 `EnableInteractivePrewarm` 显式启用受限后台预热；默认同步调用和共享 Effect 不启用。仅普通世界空间面片、有效负开始时间、恒定发射器位置与方向，且无模型、事件、运动拖尾、地形或继承速度等组合准入。工作器按原 `1/120` 完整准备范围和零时刻模拟，移交整个实例及随机状态；首份保持原先读取周期再定位的顺序，继任者保持自然重播的重置顺序。实时挂点历史只在宿主线程取零时刻值，初次等待先完成历史初始化；根、挂点、接收面或发射截止改变会取消未交接结果。全局同时最多一份准备任务：四个及以上逻辑处理器时，首次完整范围与零时刻模拟可作为两项独立 CPU 工作并行，全部结束后才交接；低核数及已缓存范围的继任者保持单项工作。每实例只预备一份继任状态，关闭与重载取消任务。等待和回交首帧不追算墙钟；后台工作量及首次实际显示仍有成本，多份重资源未及时准备时也可能暂留末帧，不能据此宣称所有组合无等待。
- 对不能使用上述完整模拟预热的复杂效果，同一显式开关允许单独后台估算取景范围；工作器只读转换快照、自建估算模拟，不读取实时挂点历史、不解析新资源或调用 GPU。实时播放照常推进，不把此范围任务视为播放准备等待。范围完整计算后仅在宿主准备帧发布一次，已有与后续共享副本读取同一不可变范围快照；取消、重载和失败不会发布旧结果。延迟自动取景只在用户仍保持原摄像机位置、角度、缩放和投影方式时生效，避免覆盖用户导航。此范围分支不放宽完整模拟预热的准入条件，不改变全局步长、寿命、数量或播放随机状态。

- 独立编辑器显式启用运动拖尾预览：循环开启、实际观察到挂点变换，且当前有效根中有普通面片或模型的正 `SpawnSpacing` 或 `TrailMode` 时，时间持续推进，不在原短播放周期或 600 秒回零。只延续这些根发射器的出生区间，有限根的发射相位按原时长循环；粒子寿命、出生随机序列、容量限制、普通非拖尾根及事件子发射器的原有有限时序保持。距离发射停止移动后不补时间粒子，已有尾迹按原寿命消失。`enable_trail_mode` 从当前画质的渲染栈读取，无该字段时兼容旧行为链；同画质重复或两处值冲突仍诊断停用，不静默择一。`TrailMode` 还参与下述受限原生距离段生成；持续时间的延续仍属于编辑器预览策略，不写 XML、不把来源 `InfiniteLife` 改成无限，也不改变共享 Effect 或旧 `Seek` 协议的 600 秒边界。

- 连续拖尾的播放器范围随本轮已模拟的最远时间增长，回看或重新播放归零时保留已有轨迹及范围；暂停、拖动进度和收起不推进。关闭循环回到原始末端并按明确定位通知轨迹，避免被误认作自然重播而清空历史；重载或停止清除本轮连续状态与范围。当前保留本次挂点采样供回放，长期运行的历史内存与浮点时间精度仍有资源边界；自动取样和 CPU 粒子检查不能代替完整官方 trail 的窗口视觉验收。

- 已准入原生距离段的交互拖尾，在非负开始时间下按记录的挂点更新端点消耗剩余弦段并计算出生时钟，避免将一次输入再拆成多个发射方向。历史回放将实际采样端点传入同一路线；暂停同时间变换不额外发射。全局粒子积分及其他发射仍为 `1/120`，普通 `Seek` 与负开始时间的准备路线不变。该受限路线的无力、无阻尼粒子按出生时钟和原速度计算位置，不重复积分回溯出生，也不把过寿命粒子夹到可见末帧；容量和原始寿命保留。曲线、方向或空间未满足准入条件时继续原路线，不能将此规则扩展为所有 trail 的原生支持或弯折外观已经通过验收。

- 独立编辑器的有限特效按实际开始时间、发射时长和粒子尾部决定重播周期；持续发射保留至少 8 秒的预览周期，最长 600 秒。初次打开默认视角时，使用独立模拟估算面片/模型范围并居中；动画模型只使用该时刻实际取样的姿态，不合并尚未播放的全部姿态。优先以默认水平接收面以上的颜色几何取景，扭曲体积和全部地下几何分别作为回退；透明模型跳过，但显式不透明角色不受粒子透明度影响。此取景不删除地下粒子，也不添加地形遮挡。保持共享初始俯仰和水平转角；不覆盖显式相机或加载期间的用户导航。稀疏纹理、大型轨迹及延后 8 秒以后的几何仍可能需要手动调整视距；范围估算不代表实际可见像素或完整显示验收。

### 发射、寿命、距离与运动

- 原始开始时间允许 `[-600,600]` 秒，负值按既有固定步长预热，不截成零。转换完成后，用与运行时相同的浮点运算核对完整引用链的开始时间上下界；任一中间运算溢出或最终超出该范围，只停用对应层并诊断，事件对子层的引用同步移除。父级偏移可以抵消有限的中间偏移，但不能恢复溢出的时间；不因扩大原始负时间范围而允许引用倍率产生无界预热。预热与最多 600 秒定位合计仍有有限步数预算，不修改粒子原寿命或全局 `1/120`。

- 原 XML 中显式字面值 `SpreadMethod="false"` 的受限发射层按出生点减去本次采样的发射器位置取得径向初速度方向，长度非零才归一化，零向量保持零；不再用独立的方位／扩散角代替这一位移。该入口不把数字字面值 `0` 合并为 `false`：数字 `0` 保留已有原生轨迹对照约束的候选角度分布；这一兼容边界不代表已还原游戏对所有 Boolean 字段的解析规则。共同条件为非扭曲、`SpawnSpacing=0`、`SpawnInheritedSpeed=0`、不使用表面法线、发射器旋转为零、恒定位置、零出生盒、半径下界非负、出生方向缺省或 `RELATIVE_TO_VFX_UP_AXIS`，且未启用粒子事件。普通 `Kind=0` 仍限世界空间与恒定初速度曲线；实际 `continuous_mesh + DEFERRED_DECAL` 的 `Kind=2` 可在世界或仅位置局部空间使用同一原生出生方向，并在每次出生时按发射器相位采样原始动态速度曲线，不能按存活粒子年龄反复改速度。原有随机上下界与随机调用顺序保留。径向速度和出生朝向的法线输入独立，缺省／上轴发射方向下的朝向法线仍为 Up，不能把径向速度当成朝向法线。模型、全局部空间、自发光贴花及其他组合未因该入口而扩大；力、阻尼、地形、网格发射和风继续受各自条件与诊断约束。出生区域另沿下条显式 `SpawnArc` 的受限规则采样；该字段缺省时仍保留原候选出生分布，不用固定地面高度或延长寿命掩盖方向错误。

- `SpawnAreaCurve` 的内外半径采样相等且为负时，按其共同幅值在发射器平面生成圆环，保留源字段和全局固定步长；这与原生固定负半径及关闭模型发射的单变量控制一致。正半径圆环、圆环带和零半径保持原处理；不等负值、混合符号及原生随机种子仍未校准，不由这一受限规则推定。

- 活动粒子按各层原始 `MaximumParticles` 独立限制，组合与单层另保留 65,536 的预览安全上限，省略字段的默认值仍为 8,192；超限明确诊断且不改源文件。绘制按固定依赖的 8,192 面片缓冲容量连续分批，保留原透明顺序、覆盖与发光次序，不让同批尾部静默丢失。固定方向、深度和零运动的 Terry 对照支持高数量先发层之后的两层仍出生；离屏像素与实际窗口另验可见性，不能把扩大容量当作其他缺失材质、地形、点光源或完整时序已恢复。

- 有限发射器仅累加每个模拟区间与真实发射时段的交集，包括末尾不足一个 tick 的部分；固定恒定速率在不同引用开始时刻的 Terry 数量对照支持该边界处理。持续发射保留原有步进，精确子帧出生年龄和动态发射率尚未同步。发射曲线的负尾段按零发射处理，其余区间继续模拟；穿零曲线与显式截零曲线有 Terry 出现/消失对照，不代表精确出生数量同步。有限、正值的粒子寿命不受预览 seek 的 600 秒上限截断，保留真实寿命参与外观归一化，参考寿命偏移仍生效；600/3600 秒控制仅验证了早期持续可见。预览时间、重播周期上限、预热和粒子容量预算不随之扩大，完整长时播放尚未验证。

- 普通面片（`Kind=0`）的 `ParticleInitialScale` 与 `ParticleInitialAlpha` 按各粒子的实际出生时刻取初始参数阶段，独立读取 `ParticleInitialParamLoopAnim`。先将出生时间和发射器开始时间分别转为 float，再相减；正时长下，关闭该开关时钳制到 0～1，开启时先作 float 余数再除时长，非正时长取零。距离发射使用段内插值后的真实出生时刻，普通时间发射使用自己的出生时刻；不能借用当前 Tick 的发射阶段、`EmissionLoopAnim` 或连续预览开关。只有这两项初始外观取样使用该阶段，Life、初速度、朝向及其他 CPU 出生参数保留各自的原取样，随机调用顺序、寿命、数量及全局步长不变。模型与贴花继续原路径并保留该开关的候选诊断；此时序规则不代表尺寸曲线、透明合成或全部 trail 外观均已原生等价。

- 每处 VFX 引用节点保留独立实例身份，其所有子发射器共享引用的开始时间、时长偏移、粒子寿命偏移、发射倍率、缩放及颜色这六个随机通道的取样权重，再分别应用各发射器自己的覆盖范围；不能共享已经求值的颜色或按值相等合并两处引用。嵌套引用按出现位置区分，每次粒子事件触发另建独立取样作用域，重播随模拟重建；各发射器仍消费原来的六次随机取样，避免打乱后续粒子随机序列。该关系有原生兄弟层缩放及颜色的同输入证据，不代表全局随机种子、各通道原生随机序列或整条弯曲轨迹已经等价。

- 出生位置与初速度分别解析。上述径向入口显式带有 `SpawnArc` 时，以 `SpawnAngle` 为仰角 a、`SpawnArc` 为从 +X 向 −Z 的方位角 b，出生偏移为 `r*(cos(a)*cos(b), sin(a), -cos(a)*sin(b))`；半径 r 在原上下界间线性取样，不能改成面积均匀的平方根分布或无条件整圈铺开。相同出生区域规则另限 `continuous_mesh + DISTORTION`、世界或仅位置局部空间、字面 `SpreadMethod=false`、无间距／继承速度／表面法线／事件、零发射器旋转与出生盒、恒定发射器位置、非负半径，出生方向缺省或为上轴；此分支只改变出生位置，保留原速度及朝向路径。动态／随机原参数继续原取样，不写 XML；保留此前随机数调用数量及后续 Life、Alpha、尺寸和朝向取样，不能据此宣称游戏种子与完整调用顺序已同步。显式区域受支持时仍保留候选诊断，模型、全局部空间、数字 `0`、缺少 `SpawnArc` 及其他未列组合不因此扩展。

- 未进入上述显式径向分支时，显式 `SpawnArc` 两端为零、未设置旧 `SpawnSpread` 且 `SpreadMethod` 为默认值时，沿发射器上方使用候选出生方向；`SpawnAngle` 不再把该情形误算成横向或向下发射。固定上下限、关闭贴地出生的四个方位角有 Terry 对照。保留已有旋转、速度、阻尼与引用变换，非零弧度和特殊扩散方式保留未映射诊断，不外推此次零弧度规则。

- 未进入上述径向分支的旧式普通面片，其显式 `SpawnSpread` 在无 `SpawnArc`，或 `SpawnArc` 的 x/y 明确为零且无 `SpawnAngle`，并满足默认 `SpreadMethod=0`、不使用表面法线且出生朝向枚举为缺省、DISABLED 或 RELATIVE_TO_VFX_UP_AXIS 时，按相对水平面的仰角取样；未设置 `SpreadArc` 时整圈分布，显式设置时按扇区从 +X 向 −Z 取样。此分支不把 `SpawnAngle` 当成方位角。原始退场烟雾的方向控制支持 `0..3` 度低平扩散及 `90` 度向上，独立地形开关控制排除了以贴地钳制冒充方向修复。保留发射器旋转与既有随机数消耗顺序；随机序列、其他分布方式、表面法线和完整力场轨迹没有由此校准。

- 固定正值 `BurstIntervalLength` 是每次发射窗口的长度，`BurstInterval` 是窗口结束后的等待时间；零间隔保持连续发射。短寿命原生控制支持这两者相加构成周期。模拟只积累发射窗口与当前固定步长的交集，有限寿命不会在等待尾段继续堆积粒子；引用速度作用于同一发射时钟。随机上下限及零长度的非零间隔仍诊断为未映射，不外推固定值控制；不修改源字段或全局步长。

- 普通面片与模型的正 `SpawnSpacing` 按发射器在世界中的移动距离发射，不再积累每秒发射率，也不在启动瞬间额外生成一个粒子。Terry 的普通面片静止、移动、零发射率及不同间隔控制支持此规则；模型沿用共享候选路径，不将面片对照扩为模型原生运动验收；零间隔保持原来的时间发射。模拟保留不足一个间隔的余量，在当前固定步长内插入出生位置，停止移动后不补发时间粒子；极小间隔受现有粒子容量与速率限制。无模型事件辅助粒子在世界及局部空间中的运动参与子特效位置；可见刚体模型沿用其各自的位置运输与事件挂点边界。复杂曲线、引用发射倍率、随机轨迹及精确原生相位继续提示候选边界，不以点数推定完整外观。

- `SpawnInheritedSpeed` 按共同 VFX 挂点的世界位置差除以未缩放预览时间差求出生速度，和原初速度相加；不把单个发射器的 EmitterPosition 曲线计入节点运动。首个样本速度为零，同时间更新只移动历史位置并保留速度；暂停恢复与倒放重播不得产生传送脉冲。继承向量在出生表示空间中作逆变换，适配固定预览时钟时只应用一次源时间倍率，不再乘挂点尺度。`SpawnInheritedDirectionBlend` 在继承单位方向与原发射方向之间线性插值后乘继承速率，不将混合结果再次归一化；零和负继承倍率保留。静态引用偏移、事件节点及特殊时钟仍按候选边界诊断，原文件、寿命和随机消耗顺序不改。

- 正 `SpawnSpacing` 且启用 `TrailMode` 的受限普通面片，另按原生距离段生产路径处理：`SpawnSpacing` 的正值用于选择路线，段长取源初速度、速度拉伸倍率、初始 Y 尺寸、寿命尺寸 Y 首值与源缩放的乘积；初速度沿当前节点与上次完整发射点的连线，不借用 `SpawnInheritedSpeed`，也不改摄像机朝向模式。段内出生位置和出生时钟插值，上次发射点及时间只推进已用完整段的比例；转弯保留余下弦段，长时间静止后的瞬移可能产生已过寿命的出生，不能重置其年龄或延寿。准入限独立世界空间、Camera-facing velocity-aligned、恒定正速度／拉伸／确定 Y 尺寸、零区域与力／阻尼／自转、单位时间／发射倍率、无事件／扭曲／专用材质／地形，并要求正等比正规挂点；动态 Y、原生尺寸表、模型、事件和其他组合保留既有路径及其候选边界。普通非 Trail 距离发射继续使用源间隔，容量及停发仍按原规则。此分支的原生生产数据与完整原版动态视觉验收分别记录。

### 朝向、自旋与角阻尼

- 是否面向摄像机由实际行为片段及其参数决定：普通 `vs_translation` 使用 `restriction`，`vs_translation_velocity_v2` 使用 `orientation_mode`，不能按是否带贴图、资源名称或名称中包含 trail 来统一判断。相机朝向模式随当前相机重建基轴；世界固定、水平约束和刚体模型继续使用各自空间规则，不因旋转摄像机而强制改成面向相机。对应模式的退化、旋转与几何边界见下列条目；分类正确不表示所有轨迹与完整外观已验收。

- 粒子出生朝向读取原生 `ParticleRelativeSpawnOrientation`：缺省和 `DISABLED` 为 0，独立粒子朝向；`RELATIVE_TO_VFX_UP_AXIS` 为 1，显式继承发射器／节点朝向；`RELATIVE_TO_TERRAIN_NORMAL` 为 2，继续既有受限地形分支。旧 `RelativeParticleOrientation` 布尔及已有 `ParticleRelativeOrientation` 兼容别名只在显式给定时生效，多个来源冲突仍诊断停用。速度拉伸模式不改变该缺省值，也不改变原发射速度的朝向规则。未知枚举继续按未支持范围报告，不将原生未知值回退策略作为已验证功能。

- 普通面片的原始粒子角按行向量 `Rx * Ry * Rz` 构造出生旋转；显式继承上轴时再乘发射器与出生节点旋转，不把欧拉角相加。独立出生的世界空间和仅跟随位置的局部空间不附加挂点绝对旋转；完整局部空间只附加出生之后的旋转差。普通速度面片共用该出生旋转，legacy 几何继续使用原平面内二维投影，不转置矩阵或强制启用实验性三维分支。无阻尼自旋按出生局部轴的连续轴角旋转组合；完整局部空间的角速度跟随、动态 EmitterOrientation 及复杂引用／事件组合仍未完整对齐。模型、贴花及事件继承不借此改变既有角度约定。

- 粒子自转读取 `ParticleSpin_Min/Max` 与各轴方向，以度/源秒推进；顺时针对应负角度，逆时针对应正角度，未填写方向时在出生时选择顺逆并保持。单轴与环斩初始水平面有 Terry 连续帧对照，引用时间倍率作用于旋转时钟；旋转不借用尺寸或贴图动画的循环年龄。恒定角阻尼 0～5 的纯 Z 自旋及零阻尼继续既有解析路径，保留已确认的方向与时钟。正恒定阻尼且配置了 X／Y 自旋的普通面片，另在世界或仅位置空间按出生完整旋转将局部角速度转换到世界，之后只衰减世界 Z 分量，再执行归一化四元数步进；保留完整旋转矩阵，不把变化欧拉角相加。该分支保留原出生随机取样，不适用于专用网格材质、MeshLoop、自带粒子事件或地形相对出生，完整局部空间继续旧路径；相对上轴出生按已有出生旋转组合。它不改变原纹理、图集、尺寸、寿命、发射、粒子顺序和共享步长，也不代表原生随机序列已还原；模型按独立 CPU 更新规则处理，见下文，不复用普通面片的仅世界 Z 阻尼。非恒定、非 Bezier 且范围在 0～5 的角阻尼，另支持无自带粒子事件／专用网格材质、独立出生、世界或仅位置空间、出生角与角速度 X/Y 均为零的普通面片；自旋须非零且方向有效。该分支在既有 1/120 预览时钟中按当前源寿命阶段取样，先以指数衰减世界 Z 角速度，再执行归一化四元数显式步进。阶段分母的 0.000001 使用源秒单位，引用时间倍率同时作用于时间差和源年龄／寿命；不足 Tick 的绘制在状态副本上推进，不让渲染次数改变运动。出生只初始化，不添加未知原生首步；这是原生更新规则在预览时钟上的实现，不证明游戏本身固定 120Hz。新增分支复用已消耗的两个独立随机通道选择速度和方向，避免改变其他出生参数；全局随机序列仍未与游戏同步。完整局部空间、多轴／相对出生、事件、Bezier／超界动态阻尼等继续诊断并省略该自转，这一动态分支不借此扩展模型或旧常量分支。

- 普通面片另支持负值或超过 5 的受限常量角阻尼：源中必须有两个实存的 `x_min/x_max` 原始通道，各只有一个关键点、float 值相同，绑定索引为 0／1；世界或仅位置空间、无专用网格材质／MeshLoop／自带粒子事件，其余出生与方向条件仍按上述两条普通四元数路径。原生 GPU 打包直接读取 raw 0／1，写入有符号 half 纹理，半精度中点按原函数向零处理，不能用模型 float 表或 `System.Half` 的默认舍入替代；half 不可表示时明确诊断。单点标注 `bezier_c` 不构成 Bezier 时间段。动态表原生按 `i/128` 烘焙后半量化并由纹理过滤，不是模型的 `i/127` 插表，因此不据常量支持放开动态、不同双表、单通道或任意链接重排。新常量先按源时间差衰减世界 Z（负值增长），再做归一化四元数步进；倾斜／多轴出生仍保留世界 X/Y，不借用模型的 XYZ 衰减。普通旧 0～5 路径与模型路径保持。角状态不可表示时仅隔离对应层并报告范围；部分帧的失败只影响该次投影，不提交到模拟历史，重播／回退恢复后仅移除本分支追加的警告，不清除原转换或模型诊断。

- 进入受限 `ModelQuaternionSpin` 路径的 `continuous_rigid` 按原生 CPU 更新：出生角速度转到世界，以 `age/(life+1e-6)` 与固定粒子权重取阻尼，先用 `exp(-lambda*sourceDt)` 同时衰减 XYZ，再执行 `normalize(q+.5*sourceDt*(OmegaWorld*q))`。负阻尼允许增长，面片的仅 Z 阻尼不变；无任意速度上限；浮点不可表示则诊断停本层。已支持的正阻尼模型分支保持；未进入该路径的恒定纯 Z、0～5 阻尼、世界／仅位置空间模型仍保留旧解析约定。负值／超过 5／Bezier 另用原生 128 点 float 表，`t=float(i)*float(1/127)`；Bezier_c 采用原生十次参数二分及随后扫描，保留原切线及 float 端点函数；运行时按时间及粒子权重插表；普通曲线不变。FullLocal 自旋后按原生当前节点共轭同时运输姿态／角速度，不重复出生朝向；常量分支保持。动态 EmitterOrientation 烘焙 XYZ min/max 四元数表，时间及控制器权重均按组件插值后归一化，不插值 Euler、不翻转 q 符号。出生与跟随共用控制器权重。出生循环单独读取 `EmitterOrientationLoopAnim`；后续跟随循环取源 InfiniteLife 与父实例允许循环的交集，父 false 仅关闭跟随循环。预览以 Start 为源时零，用发射器 duration／时间倍率取连续端点，部分 Tick／同时间只算副本。原生先更新再推进时钟，实际首帧标签偏移与游戏时钟未标定，端点映射不代表游戏同帧。事件不再一概阻断已校准的模型四元数和动态位置路径；MeshLoop、非正规挂点、step／未知模式、flag0 不同表、反向 q 消去和完整物理仍有限制；MathF 三角精度不作 SSE 逐位承诺。全局 `1.0 / 120`、出生随机调用及原件不变，不宣称游戏固定 120Hz 或全部 trail 已验收。

- `continuous_rigid` 的受限 FullLocal 动态发射器另按原生 CPU 规则运输位置及速度：`EmitterPosition` 使用原生 128 点模型曲线，动态发射器四元数使用既有烘焙表，两者共用控制器权重与跟随时钟。每个完整 Tick 提交状态，部分 Tick 及事件挂点只计算副本；运输包含前后节点和发射器的位移、旋转，不把它当作骨骼动画或普通面片更新。当前生产映射仅允许单位正缩放的正规根节点与单位继承尺寸；非单位缩放显示专属范围诊断，不宣称已校准。原生运输公式的数值控制并不证明任意场景缩放都能正确映射。原始粒子寿命、普通模型自转、纹理及模型材质各自的支持边界保持。

- 显式全／半分辨率普通面片另使用有条件的原生外观表：`ParticleScale`、`ParticleInitialAlpha` 与生命透明度的解析区间按普通 GPU 规则烘焙为 128 点 half 表；仅已验证解析模式、有效上下表相等且对应生命透明度偏移为零时准入。尺寸与生命透明度使用 float `age/(life+1e-6)` 采样，初始透明度保持独立出生参数阶段和原随机调用。模型的 128 点 float 表、旧曲线直接求值入口及已准入 quadratic 尺寸分支保持独立；Bezier 透明度、不同上下表和非零偏移继续原候选路径。half 表字节可精确核对，但便携线性过滤与真实 GPU 的最后半精度舍入仍可能不同。不用外观表改物理时钟、过期判定、原始寿命、RNG 或距离 trail 的 CPU 发射段距。

- 普通面片的 `Camera-facing velocity-aligned`（原生 legacy mode 2）直接归一化视线与速度的叉积，近乎平行时也不切换到摄像机右轴；叉积为零或 float 下溢而无有效平面时不绘制该面片。`Camera-aligned with stretching factor`（mode 5）的右轴混合回退保持独立，模型、水平约束和其他朝向不借此改变。该几何分支由原生着色器和相同输入角点验证，不能外推完整材质在所有视角下已经保真。

- `vs_rendersize_limiter` 使用面片所在原始渲染通道的实际视口宽度：显式 `HALFRES_DEFERRED_ALPHA` 普通面片使用半宽视口，其他现有通道保留完整宽度；没有有效视口时保留不放大的兼容路径。按原生欧氏摄像机距离、投影 X 尺寸及 half 量化的原始像素下限求同一比例，共同放大 XY，不修改距离发射段长、粒子寿命或发射数量。此处仅还原几何尺寸计算；当前普通颜色目标与 MBOIT／半分辨率重建仍有限制，继续保留相应诊断。

- `vs_translation_velocity_v2` 的水平朝向仅适配普通面片，以世界竖轴与归一化速度组成平面，沿用先平面内旋转、再沿速度轴拉伸的顺序；零速度或完全平行竖轴时省略退化面片，接近竖直时保留并归一化横向基轴，不改用摄像机基轴。发射角及扩散角均缺省、发射器旋转为零的水平面片使用固定方位的竖直浮点候选方向，保留极小横向分量，避免将其随机方位放大为整张面片的随机朝向；原生竖直轨迹和近竖直面片有控制对照，极小分量的原生位模式及随机序列尚未同步。固定方向和深度的基础尺寸、拉伸参数为 0 及上限为 1 有 Terry 控制对照；任意拉伸倍率、其他出生方向和运动组合仍是候选解释。原生尺寸对照须使用相同的 `scene_view_type`，默认与显式全分辨率通道的边缘像素不能直接视作相同；不以全局尺寸或亮度补偿代替原生差异。普通平移面片的水平约束另按下方四种限制规则处理；非等比缩放与完整原生外观仍须单独验收。`Particle only rotating around local Y (horizontal)` 另按随游戏提供的着色器保持水平平面，仅用速度的水平投影决定方位，拉伸仍取完整速度长度；复用原平面内旋转、零／竖直速度退化及缩放诊断。速度朝向的世界空间粒子在未启用相对朝向时，不把参考节点旋转再次投影到粒子平面；参考旋转仍作用于出生位置和速度，避免 90° 参考旋转将面片压成零面积。完整局部空间及显式相对朝向按上述出生旋转与后续差值处理，复杂组合仍需更多原生对照。它不因上升或下降速度而倾斜面片，实际随机方位、运动时钟与完整外观仍需原生对照。旧版速度着色器、模型的水平朝向以及普通平移的其他未支持限制选项继续诊断。

- 普通 `vs_translation` 的 `restriction=0/1/2` 先用完整粒子旋转变换局部 XY，再取结果 XY：分别放入相机平面、相机横轴与世界竖轴、世界 XZ 水平面；不能先丢弃原 X／Y 角。`restriction=3` 保留完整三维旋转。水平烟片不随挂点绝对旋转倾斜；显式继承仍会改变投影后的形状。摄像机朝向及竖直面片在编辑器反向投影时成对修正顶点横轴与二维旋转；固定空间面片不套用该修正。着色另保留完整旋转：0/1 乘逆视图、2 乘 X90、3 保持世界基；不能从投影后几何分解重建原法线。已有天气光照分支接收完整旋转四元数及投影前有效 X 尺寸，速度 v2 保留既有 Y180 法线修正；不扩大未支持的光照组合。模型、投影贴花及共享相机初值不借此改变。

- 未进入“朝向、自旋与角阻尼”中的刚体四元数更新分支的模型粒子，仍按 X、Y、Z 顺序相乘，再接调用方根变换；继承模型朝向的事件子特效使用同一基轴。原版锥形与冰块的固定角度、零运动控制支持此顺序，避免固定 X 加随机 Z 的束状模型错误向四周散开。此规则不改变发射器、VFX 引用或普通空间面片各自的旋转约定，也不改变原始角度、轴心或随机序列。多轴自转的组合和任意旋转挂点仍需原生对照；轮廓一致不代表材质、光照或完整动画已验收。

普通面片的受限动态角阻尼另读取原生 GPU 的 `i/128` 烘焙表：要求实存 `x_min/x_max` raw 0／1、对应绑定 0／1、两表的关键点／模式／切线记录一致，仅接受已核实的非 Bezier 解析模式，烘焙后按原生有符号 half 转换。归一化纹理坐标对应 `phase*128-.5`，边界夹取最后实际 texel，而不是补入源曲线在 1 的端点；两表相同使随机权重不改变阻尼。世界／仅位置空间的新增动态分支限独立出生、出生角和自旋的 X／Y 为零、无专用网格材质／MeshLoop／粒子事件；这条路径扩展负值／高值动态曲线，已有世界／仅位置空间的 0～5 动态路径保持原约定。采样采用可移植的线性过滤几何，不硬编码某块 GPU 的子纹素精度或输出舍入；原生烘焙值可逐位检查，过滤数值不承诺跨 GPU 逐位相同。不同双表、缺表、未知绑定、Bezier 段和 half 溢出仍明确诊断。

完整局部空间的普通面片另支持恒定发射器朝向、独立出生、出生角和自旋的 X／Y 均为零、无专用网格材质／MeshLoop／粒子事件／地形相对出生的上述 half 常量或相同动态表组合。粒子保存世界角速度向量；每步先衰减世界 Z 并更新自身四元数，再以 `currentNode * conjugate(previousNode)` 同时运输姿态及角速度。恒定非零发射器朝向在原生局部增量中相消，不能重复乘绝对发射器或出生节点旋转。运输后的 X／Y 角速度在下一步保留，不套用模型的 XYZ 衰减。Tick 提交姿态、角速度和节点旋转；绘制与暂停时的当前挂点只计算副本，包括零时间差的节点变化。纯 Z 出生复用已消费的随机通道，不改变后续粒子的非角参数；原生随机种子仍未还原。正等比正规节点属于已核实范围，非等比／镜像／剪切继续显示候选诊断；动态发射器朝向和新增复杂出生组合仍不在此分支内。

### 力与线性阻尼

- 只有 Force 各轴的原始上下界通道都恰有一个有限关键点，且不走原生预烘焙尺寸路径时，才可在出生随机字段确定后缓存原力取样及单位换算；不增加随机调用，速度和位置仍逐 Tick 更新。多关键点同值不代表 Bezier 恒定，动态力与动态阻尼继续按原进度取样。世界空间粒子的出生根不随当前挂点改变，其力基支持判断可复用；局部空间仍在需要时读取当前根，诊断边界保持。

- 普通 `Kind=0` 面片的线性阻尼保留作者的符号，按 `exp(-lambda * sourceDt)` 更新；负值对应速度增长，不能截成零。此规则与角阻尼分开，模型及投影贴花仍沿各自已有支持范围，不把普通面片的线性规则移植到其旋转。

- 无阻尼恒力仍限普通面片、零初速度、零发射器旋转、平移及正等比缩放挂点、单位时间，按 `ForceA.Y * 0.01` 施加局部加速度；原生等比缩放控制支持其位移随缩放变化。受限恒力与阻尼组合另限无扭曲、无速度朝向的普通面片，显式 `SpawnAngle=0/0`、`SpawnSpread=90/90`、`RELATIVE_TO_VFX_UP_AXIS` 和默认分布方式；未设置 `SpreadArc` 的旧式分支即使保留整圈方位取样，固定 90° 仰角仍属于已校准的竖直组合，不因此丢失受限积分；显式非零扇区及非零原始方向不扩展。发射器位置/旋转及随机发射区域为零，粒子寿命不超过 4 秒，其他力与风为零。已验证的参数组合为：初速度 0 或 1、阻尼 1 或 5、竖直恒力绝对值不超过 200；恒力绝对值不超过 50 时，另支持初速度 0、0.5、1、2 与阻尼 0.5、1、2、5、10 的交叉组合，以及初速度 0.75、1.5 与阻尼 0.75、1.5、3、7.5 的交叉组合。这些离散组之外的中间值及跨组配对继续诊断，不推定已获验证。该分支采用原生控制支持的 1/60 秒“先加力、再指数阻尼、后移位”候选轨迹，并在显示时插值；共享模拟 tick 及其他运动仍为 1/120 秒。挂点/引用合成变换必须只有平移，总时间倍率为 1、引用寿命偏移为零；不满足时保留诊断并省略恒力。此结果不证明原生引擎具有固定的 1/60 秒步长，也不覆盖任意方向、动态/随机力或其他阻尼值。

- 普通面片的 ForceA 曲线另按粒子寿命进度采样，以原生控制支持的 `0.01` 单位换算施加加速度，再应用当前寿命进度的指数阻尼和位移，沿用全局 `1.0 / 120`。此分支要求发射器旋转为零，ForceB/ForceC、模型表面发射、地形跟随及表面法线发射关闭；非零风参数不再阻断独立的 ForceA，但风与风变化仍保留未映射诊断，不能称风场已实现；挂点仅允许平移及正等比缩放，时间倍率为 1。自旋衰减不再阻止平移力生效。原生对照覆盖竖直恒力、线性变化的竖直力、变化阻尼及等比缩放；任意方向、随机采样与原生种子、旋转和非等比挂点及完整效果外观未全部校准，继续显示候选诊断。原有离散恒力与阻尼分支不因这个候选扩大其变换范围。

- 缺省发射的受限恒力组合另支持普通、无扭曲、摄像机朝向或水平朝向面片：初速度恒为 -10、阻尼恒为 0.1、竖直 `ForceA` 约为 -981（仅容纳原作浮点写入误差）、寿命不超过 0.4 秒，发射角、扩散角和相对发射方式均缺省，发射器旋转为零。发射位置/区域仅允许全零，或原作的固定位置 `(0,4,0)` 与固定盒区域 `(2,3,2)` 配对；其他力、风、地形跟随和事件为零。沿用上述 1/60 候选积分、平移挂点与单位时间边界，并保留初速度中极小的横向分量。原生控制用粒子颜色编码年龄，同时校准静态色阶与空间原点，按颜色量化得到的年龄区间验证轨迹；不能把截图时间戳或不同运动分支的同帧位置直接当作准确粒子年龄。此离散组合不扩展其他初速度、阻尼、力值或方向。

### 图集与纹理动画

- 外层 `atlas_number_of_cells_x/y` 的整数 0 按原生常量生产端逐轴归一为 1，再计算缩放、偏移及校验外层格号；内层动画格数仍须为正整数。保留原始 XML、格序、相邻帧混合和色彩规则，负数、小数与现有安全上限仍诊断。

- `vs_cell_texture` 的非负整数格号按子图集格数循环；随机选格在基础格号上叠加整数随机偏移后再循环，保留原始格号数据。`vs_animated_texture` 的寿命模式先按寿命阶段插值 `no_loops` 两端，再乘该阶段；固定速度模式以源时间秒数乘相同阶段频率。随机起帧使用连续相位，保留相邻帧混合的小数；随机行独立于单行限制，行偏移只加一次，越过图集末行的 UV 交由原寻址规则处理，不预先折回。`trail_distribution` 仍保留未支持诊断；其原生格序依赖打包粒子 ID，不能用无限递增发射序号代替尚未核实的分配／复用规则。`vs_flip_uv` 在每个图集单元内先执行原始／顺逆 90° 旋转，再按两个轴的概率翻转；两轴分别以同一粒子随机值的 `frac(r*251)`、`frac(r*149)` 与原阈值比较，不额外消耗出生随机数。普通面片固定端点有历史原生色块对照；旋转只重排贴图对应的顶点，不旋转粒子外形或偏移中心，相邻帧偏移仍使用正的单元尺寸。全局随机种子尚未与游戏同步；模型及扭曲贴图的 90° 旋转继续诊断并保留未旋转显示。

- `vs_animated_texture` 的 `fixed_animation_speed` 候选分支按源时间中的存活秒数乘当前频率播放，频率在 `no_loops` 两端之间按粒子归一化年龄插值；引用时间倍率作用于源存活时间。随机选格使用连续相位偏移，保留既有出生随机序列。固定方向与深度的单粒子尺寸/色块控制支持其与寿命比例计时的区别，但仍有切换帧未落入当前候选的观测区间；相邻帧混合、随机相位与原生种子不宣称完全同步。原有寿命计时分支不变，拖尾分布等其他计时模式继续停用受影响层。

### 普通面片、透明度与自发光

- 普通带 `ps_texture`、无专用材质面片的 `ps_alpha_crush` 支持预乘与非预乘组合：先处理纹理／渐变，再将纹理透明度与原始粒子透明度相乘并饱和，随后按原始 `progress` 曲线及 `sharp_transition` 裁切；预乘路径的覆盖与独立发光形状分别处理。原始覆盖为零、进度为负时，非预乘路径保留原生恢复的黑色覆盖，不重新引入纹理 RGB。裁切先于场景软深度淡化，发光颜色与权重保留各自的软边因子。进度随粒子寿命采样，同一绘制层的不同粒子保留各自阈值，倒放重播保持确定；不修改来源。DISTORTION 的裁切见“DISTORTION 与加权合成”，专用模型及自定义像素着色器仍各自处理；原生随机序列、曲线烘焙精度及完整透明合成仍需对照。

- `vs_vertex_alpha` 的 `alpha_START_offset`、`alpha_END_offset` 使用同一粒子随机权重重新映射透明度曲线的寿命坐标，再乘初始透明度；不改变运动、模型动画、颜色或全局步长。粒子事件继承透明度时采用同一映射；空或反向窗口保留诊断，不产生非有限输出。

- 普通预乘面片保留初始透明度与寿命曲线相乘后高于 1 的值，在纹理取样后计算覆盖饱和与边缘收缩；预乘颜色仍使用饱和后的粒子透明度，不随锐化重复增亮。强弱透明度粒子保持原绘制顺序，数值范围相差很大时不能因颜色字节编码丢失弱粒子。此规则有原生渐变遮罩、同位置消失后背景及离屏浮点像素对照；其他材质路径、曝光、完整透明排序和原始环斩出现时序仍未全部还原，不改变全局模拟步长或默认出生规则。

- 普通非预乘纹理面片同样保留非负的原始粒子透明度，包括高于 1 的值；统一在材质中先混合原贴图／图集帧，再按原生 `ps_texture` 线性化 Alpha、执行可选渐变映射，最后与粒子透明度相乘并饱和。不能提前截断粒子透明度，也不能只在跨过 1 时切换 Alpha 的颜色空间；RGB 的 sRGB 硬件采样与 Alpha 的上述转换保持独立。无纹理纯色使用原有单位白纹理，转换对全白 Alpha 恒等；模型、投影贴花、自定义材质和扭曲不借此扩展。原有普通范围内灰度 Alpha 的覆盖差异属于旧路径修正，不以保持旧错误像素作为兼容目标。

- 普通面片的 `ps_custom_shader` 另支持 `fx_animated_uvs_custom.xml.shader` 的候选材质：保留七个显式资源及原始参数，按全局材质时间滚动，各遮罩读取着色器指定通道，粒子透明度在最终组合前保留超过 1 的原始值。为适配固定依赖的六个纹理槽，数值噪声与全局遮罩原分辨率打包到带循环边缘的纹理，各自 UV 独立；输入缺失、解码失败或打包超出 4096 尺寸预算时停用依赖该资源的层，不影响其他层。原生连续帧支持贴图绑定和滚动速度，离屏浮点像素覆盖内在颜色/透明度公式；完整雾、MBOIT 透明排序、最终曝光及其他自定义着色器仍未还原，不能把可转换视为完整外观通过。

- `wh3_vfx_custom_basic.xml.shader` 的普通面片另保留四张资源和原始参数，按随游戏提供的着色器读取颜色乘法/叠加、透明度幂、发光遮罩与全局时间扭曲。当前只支持关闭视角反射变化的分支；其他参数拒绝而不套用近似普通材质。克隆材质在 Terry 中未表现出独立参数变化，这组对照不能用于标定；未修改原始火焰可作可见性与连续动画参考。最终颜色空间、曝光、雾、透明排序和光源层尚未恢复，基础自定义材质仍持续提示候选限制。

- `wh3_vfx_custom_basic_pre_lit.xml.shader` 另保留原五张纹理与 21 个参数，使用独立面片材质读取内在颜色、原始透明度、材质图的漫反射份额及全局滚动的绿色发光遮罩；当前仅支持未按太阳颜色缩放发光的分支。漫反射按 sRGB 采样，数值资源默认线性并保留 DDS 的显式 sRGB 格式，法线保持线性；同位置原生等效输入支持旧 DDS 的用途规则，显式格式沿用共用纹理解码契约。原法线资源和参数保留，但完整 PBR 法线光照、金属反射、雾、MBOIT 与最终明暗尚未还原，普通白色控制在程序中仍偏暗，持续给出候选限制；转换或有像素不表示原生外观通过。

- 普通预乘面片和普通模型只在完整解码贴图确认透明度全为 0 或全为 1、且不使用渐变、自定义材质或投影贴花时，省略恒无贡献的遮盖或发光通道；沿用固定 DX11 后端的 MAX Alpha，核对全部 RGBA 而非只比较颜色。缓存复用相同资源的判定，重载重新检查；中间或混合透明度继续保留原通道。有通道被省略时，仅在各粒子的颜色与透明度归一化尺度一致时合批，保留排序与弱粒子，不能用同批最大亮度吞掉较暗内容。不改游戏源件、出生、寿命或全局模拟步长。

- 普通颜色面片没有 `ps_texture` 且不含其他未支持像素片段时，按无纹理的粒子颜色绘制，内部使用乘法单位白值接入既有材质；不调用资源解析器寻找空路径。该分支有 Terry 纯色面片对照，不适用于缺少已指定贴图、自定义着色器、扭曲或投影贴花，模型仍读取自身材质。

- 无光照或发光片段的普通预乘颜色面片保留纹理自发光，未指定倍率时按 1 绘制；缺省、显式 0 与显式 1 的 Terry 控制已验证，显式值仍优先。该缺省不扩展到模型、扭曲或投影贴花，也不补偿最终曝光；有光照或发光片段但缺少参数的其他情况仍按既有候选分支处理。

- 普通纹理面片（预乘及非预乘）和 DISTORTION 在原生桥上传前按 Alpha 的指数范围分组；正弱值使用小于 1 的浮点归一化倍率，经材质恢复原透明度，避免亚字节透明度被 8 位顶点色取整为零。精确遮盖／发光分组也保留各粒子的浮点倍率；未使用负进度裁切的零值仍无贡献，强弱粒子、顺序与大于 1 的覆盖按原语义处理。其他材质路径不借此扩大支持。

- `vfx_gemstone_crystal.xml.shader` 的基础预览另限材质 `alpha=1`，此时屏幕抖动裁剪不会丢弃像素，保留其余六个纹理绑定与原始 40 个参数。按原生着色器及同位置 Terry 对照，粒子透明度控制噪声溶解轮廓和发光边缘，不能改成整块透明混合；保留纹理着色与视线边缘响应，实体部分写入场景深度。其他材质透明度仍诊断。该基础分支未重现游戏延迟光照的金属反射、微表面法线和完整明暗，不以普通漫反射或白色模型替代；受支持的静态模型列表仍按出生选择一个。原生随机种子、角色挂点运动及完整颜色响应仍待对照。

- `wh_vfx_mesh.xml.shader` 使用独立候选材质读取原文件六张纹理与参数，组合三张滚动通道遮罩、颜色叠加、扭曲、全局遮罩和原始顶点 RGBA；旧格式 DDS 的遮罩按线性采样，显式 sRGB 格式按原标记采样，不用普通漫反射替代。同时支持 `wh2_vfx_mesh_colour.xml.shader` 的无扭曲颜色分支，以及 `wh3_vfx_one_shot_mesh.xml.shader` 的颜色扭曲为零分支；后者保留原始六个有效纹理输入，外观遮罩使用粒子寿命进度，全局滚动使用全局时间，精确遮罩相位仍为候选。 `wh3_vfx_basic_mesh.xml.shader` 的零颜色扭曲分支另按原始三张通道贴图、纹理幂、两张边缘遮罩及其饱和强度、颜色叠加和顶点透明度绘制，使用全局滚动时间；不再以一张普通漫反射替代该材质，启用颜色扭曲时仍停用该层并诊断。一个几何体可包含至多 64 个受支持材质的网格，各部分共用同一模拟粒子，保留各自材质与顶点透明度；模型写回和旧顶点解码不变。单粒子、零初速度、零力、零阻尼的该类模型可按有效 `ParticleLoopParams` 区间循环外观年龄，发射器结束后走完剩余寿命；持续显示有 Terry 单变量对照，精确相位及退出时间仍为候选。场内 VFX（普通面片与模型）在普通 8 位颜色目标前使用同尺寸、同采样数的缓存浮点目标合成；普通场景的多个实例在上述显式作用域内共用该目标，独立 `Draw` 则保留单次调用内的浮点目标，保留原场景深度并恢复 DX11 目标和状态，防止薄而亮的粒子在透明混合前丢失颜色；8 位输出前在合成结果上应用已对照的固定曝光、原生色调映射、gamma 2.2、受限天气统一对比度和默认色彩查找表。已有场景背景先按同一变换逆算再参与合成，未受 VFX 影响的像素保持原值，避免重复处理共享场景；无法恢复背景已经截断的 HDR 亮部。浮点离屏目标继续输出未经后处理的线性值；8 位显示的共用泛光边界见下文。静态 RigidData 列表可包含至多 32 个受支持模型，按 Terry 列表对照在出生时选择一个，存活期间保持选择；同一模型的多个网格共同绘制，不把所有备选模型叠加。引用组合同步偏移全部变体资源，初始取景包含所有备选模型；原生绘制层和材质总量分别受 512 和 256 的边界约束。随机种子、列表选择权重仍未与游戏同步。复杂层级的刚体分块动画、未指定动画的蒙皮、单个 wsmodel 内的多个几何体和其他专用模型材质继续诊断；标准蒙皮动画的受限路径见下文。

- 普通面片读取当前画质显式填写的 `ParticleCullDistances`，按当前发射器的正均匀根缩放与继承缩放调整近端淡入／远端淡出四个距离；世界粒子也读取当前发射器缩放，不沿用出生时根缩放。距离到变换后的粒子中心，近端与远端插值分母保留原生 `1e-6`，远端上界不绘制；这只影响当帧显示，不删除粒子或重启运动。缺省字段保持原路径；非均匀、反射或剪切根变换不猜测缩放，保留原显示并给范围诊断。自动取景不使用虚拟摄像机的距离裁剪，避免短距离效果被误判为空。此规则不扩展投影贴花，也不替代发射器 `CullDistances`。

- 普通面片的游戏标准着色器（非自定义网格材质）保留原生两个低透明度关口：先比较发射器及继承 Tint Alpha 乘距离淡入，再比较包含初始／寿命透明度的最终顶点 Alpha；两次均须严格大于阈值。`CommonShaderParameters.VfxLowOpacityCulling` 默认采用原生全局值 `0.01`，显式覆盖仅用于渲染诊断；游戏本身也能覆盖该全局值，不能称任何配置下都固定为此值。贴图透明度在像素阶段取样，不参与这两次顶点裁剪；粒子仍按原寿命模拟。模型、贴花及自定义网格材质没有套用此未校准规则。自动取景绕过两个关口和摄像机距离淡入，原始透明度曲线仍用于排除完全无可见贡献的几何。

- `wh_vfx_mesh` 与 `wh2_vfx_mesh_colour` 按游戏技术状态剔除背面，并随投影反射选择对应绕序；不再把模型正反两面一起叠加。模型预览读取当前画质的 `ParticleCullDistances`，按粒子变换后的世界位置到摄像机的距离计算近端淡入、远端淡出，范围外停止绘制；各网格共用同一粒子的透明度，距离变化不销毁粒子或重启时钟。等值端点使用硬边界。固定相机、原始模型与贴图的 Terry 单变量控制支持近端隐藏、中间衰减和等值近端的可见性；线性中间值仍为候选，最终明暗及完整特效动画另行验证。此规则限模型粒子的显示，不代替发射器 `CullDistances` 或普通面片的距离规则。

- 静态模型在粒子缩放、旋转之前使用原始网格顶点加 RMV 材质头轴心，再减去 `RigidData/PivotPoint` 相对默认 `(0.5,0.5,0.5)` 的偏移；该字段按模型局部单位处理，不按包围盒归一化，也不移动发射器。每个网格保留各自材质头轴心，备选模型缓存区分入口轴心。静态树枝的默认、单轴轴心及原版冰块的缩放与组合旋转 Terry 控制支持此规则，原始几何、法线、材质和资源不改写；已有刚体及蒙皮动画路径保持原处理，非默认入口轴心的动画仍继续诊断。轴心位置校准不代表光照和完整外观已通过验收。

- 标准双骨骼、四骨骼的 VFX 模型可读取显式 `AnimFile` 和对应 `animations/skeletons/<SkeletonName>.anim`，使用现有骨架、动画通道和逆绑定变换生成候选姿态；两个格式的最后权重按随游戏提供的顶点着色器重建，不修改格式写回或其他模型工具。同一模型的普通纹理网格也全部保留，多个网格共用一个粒子，动画范围参与初始取景。播放关联粒子寿命进度与 `AnimSpeed`，在该进度内按片段记录的帧率和时长取样，末帧之后保持该姿态，零速保留第一姿态；真实片段的相对周期已有原生对照，精确姿态、任意端点、材质和游戏完整外观仍未通过验收。该时钟不改变共享动画播放器。当前限默认模型中心和标准骨架，以独立姿态采样适配原生模型接口，共享模拟步长不变；单片段最多 1800 个姿态，整个组合的动画几何按全部姿态累计，以 `72 × 顶点数 + 4 × 索引数` 计算，合计最多 96,000,000 字节，另保留 600 万个索引的上限；托管姿态预算与原生 `ModelFrames` 上传采用同一配额。超限停用受影响层并诊断，不裁剪烘焙帧数、降低采样或改变原播放速度与姿态。该配额不是进程峰值内存承诺：托管数组、原生序列化副本和 GPU 缓存等仍可能同时存在。同一次顶层转换内，路径、网格、动画、速度、寿命和枢轴均相同的模型跨引用及事件复用几何；各粒子、挂点和实例仍独立，重复模型通过原生别名上传，不重复占用动画配额。层、引用或事件转换失败时，同步撤回该次新增的模型缓存与姿态配额，保留此前成功资源，避免虚假缓存或连带阻断后续有效层。Terry 导出保留 Mod 显式动画的原始字节，原版动画复用游戏资源。

- `wh2_vfx_cst_tidecall.xml.shader` 使用独立候选模型材质，保留原 368 字节参数及十二个逻辑纹理绑定。按内容及用途复用资源，超过六个像素纹理槽时使用额外 DX11 绑定，保留原 DDS 缩小层；顶点位移独立采样原纹理 mip0 的蓝通道，按粒子年龄滚动，沿归一化世界法线乘原强度与 `(1-UV.y)`。泡沫、噪声、纵向遮罩和主消解使用材质全局秒时钟，波浪与消解遮罩使用粒子年龄；粒子透明度千分位截取后参与阈值与屏幕抖动裁切。沿用原生单面剔除、不透明覆盖及写深度，额外常量、纹理与采样器在绘制后恢复，不用普通透明混合或图集替代。当前输出内在底色及泡沫，原 normal 参数与资源保留，完整延迟法线光照、反射、精确材质时钟及抖动相位仍未还原；完整官方样本的离屏可见性不代表原生动态外观验收。

- `wh_vfx_mesh_vertex_anim_battle.xml.shader` 使用独立候选模型材质，保留原 256 字节参数和六个逻辑纹理绑定。原 VS 使用模型顶点红色作为正弦振荡权重，以世界位置和所选时钟生成单一标量并加到世界 XYZ；纹理位移另取原纹理 mip0 蓝通道，乘世界法线 X、原强度及 `(1-UV.y)`。此图未读取 Y/Z 振荡参数、UV2 或顶点 ID，仍保留原字段，不自行增加三个振荡轴或改白零顶点色。PS 保留再次计算偏移后的视角淡化、三路滚动通道值相乘、全局遮罩、顶点 Alpha 平方和独立粒子颜色，按原预乘输出、单面剔除、测试深度且不写深度；专用常量及 VS/PS 位移资源在绘制后恢复。原 `fog=1` 选择无雾底色，完整原生雾及第三路贴图的逐实例 UV 偏移尚未还原，精确材质时钟与完整透明合成继续诊断；模型的动画权重全零或位移关闭时，静止几何是有效原始行为，不能用强制动画冒充修复。

### 深度、软边与地形

- `RELATIVE_TO_TERRAIN_NORMAL` 另支持受限静止投影贴花：发射位置、旋转、随机发射区域、速度及力为零，无风、网格发射或持续跟随地形；绘制时必须由调用者显式提供水平接收高度；除下述世界空间贴地分支外，根变换仍限平移。启用贴地出生时，当前发射点还须已位于该平面，不自动猜测落地高度。平面上的正、负 90° 朝向及贴地出生开关有 Terry 上轴/地形法线对照；缺少平面、旋转缩放挂点或其他出生高度时跳过该贴花并诊断，恢复条件后可继续预览。普通面片和模型的静止分支另以显式水平面提供上轴法线，限零初速度、零发射器旋转、零力，无风、网格发射或持续跟随地形；保留原位置、出生范围、模型、尺寸与粒子旋转。贴地出生按地面加本地出生高度计算，忽略挂点的竖直平移；不贴地时保留原世界高度。贴地出生另允许无旋转且无镜像的正等比根缩放，尺寸随比例改变，但原本地高度偏移不缩放；静态模型有原生等比缩放对照。未贴地的缩放、非等比或其他根变换继续诊断，投影贴花的扩展挂点组合仅限下述世界空间贴地分支。有效静止地形层绘制前，在视锥与该水平面的交集中写入无颜色的地面深度，沿用场景深度测试，使地下、平面中央与地上面片产生正确遮挡；缺少深度附件时跳过相应层并诊断，恢复有效目标后可继续绘制。共享 Effect 未显式提供地面时不猜测高度。上述静止分支不适用于移动粒子、斜坡或真实动态地形法线。
- 世界空间、贴地出生的静止投影贴花另支持正等比缩放与旋转骨骼挂点：先沿既有出生分布取得世界 XZ，再由水平地形查询替换 Y，尺寸保留挂点缩放。朝向使用该普通粒子原生生产端的 `qz*qy*qx` 与独立接收面法线对齐，不能套普通面片或模型的帧旋转。出生位置、速度方向和朝向法线是三个独立输入；水平接收面的朝向法线始终为世界上轴，不随径向出生点或骨骼旋转而倾斜。方向缺省为 1；现有方向 0/1 仍限显式 `SpreadMethod=false`，但方向仅约束速度通道，不能把径向速度向量接成朝向法线；方向 2 查询水平接收面也得到上轴。底层朝向函数对显式零法线的 +X 回退仅为数学边界，不代表生产端传入零法线。此分支仍限零发射器位置、旋转、速度及力，不支持非零粒子旋转速度、非等比、剪切、镜像、局部空间扩展或斜坡；未知方向分布继续诊断，不能仅取消守卫。

- 绘制复用当前摄像机和硬件深度；软边默认从当前深度附件取得深度（独立柔边图见本节的 `VfxSoftDepth` 条目），多重采样深度通过独立解析后传入 Effekseer。扭曲复制当前背景，已确认的 DXT5n 法线将透明通道中的横向分量转换为渲染器使用的通道，其他未确认的扭曲法线编码会诊断并停用预览。桥接恢复原有绘制状态；明暗颜色通过浮点数据和材质倍率传递，批次亮度保持浮点，旧兼容面片的相对 RGB 仍经 8 位顶点颜色量化；已准入原生透明通道直接传递原始浮点 RGB，wh_vfx_mesh 另传递浮点粒子颜色；普通面片的显式天气与固定曝光入口见“天气、光照与显示输出”，自动曝光及完整场景分类泛光仍未重现。`vs_translation_velocity_v2` 的两种摄像机相关朝向按游戏着色器库旧版分支计算倍率拉伸、上限、拖尾模式及视线投影修正；非等比/镜像挂点缩放会保留基础尺寸并诊断，游戏实际运行分支仍待原生校准。预乘颜色使用 Effekseer 自定义材质，在原始纹理过滤及图集相邻帧混合后，按游戏库顺序转换透明度并拆成透明覆盖/自发光两次绘制，读取自发光倍率；同层保留既有从远到近的粒子顺序，每个粒子的覆盖与自发光相邻，避免前方覆盖之后重新叠加后方粒子的发光；两次绘制均保留场景柔边深度。默认通道、无渐变映射的普通预乘面片，其独立纹理发光按原纹理发光部分的亮度、原始粒子透明度及饱和后的自发光倍率形成形状权重，再乘粒子色和发光倍率；不以粒子颜色计算形状，软深度同时作用于发光颜色及权重。显式其他通道、渐变、模型及贴花不套用这条受控规则。纹理色彩空间与同材质重叠有 Terry 等效输入对照，受限天气响应与固定曝光以外的游戏光照、自动曝光、天气调色、完整场景分类泛光及完整透明组合仍未全部重现。显式全／半分辨率普通面片在下述整组准入范围内使用七矩透明累积；混入未准入材质时整组恢复既有覆盖／发光顺序，保留候选诊断。无阻尼的竖直恒定 ForceA 保留受限换算；已单独校准的恒力与阻尼组合沿用“力与线性阻尼”中的受限轨迹，普通面片的其他 ForceA 曲线按“力与线性阻尼”中的候选分支预览并诊断证据边界。上述受支持滚动遮罩分支以外的专用材质、动态灯光、未覆盖的粒子事件、其他力场和部分旋转/间距语义尚未适配，逐字段给出诊断。不能把部分层可见或全部可见层进入转换描述为完整保真支持。原始游戏文档始终是编辑与保存的权威来源，转换不删除未知字段。超级视图 Effect 的多实例身份、版本缩放及尚未实现的 META 设置边界见 [superview.md](superview.md) 的“Effect 的共享特效预览”；不能以部分参数生效推定全部 Effect 设置已还原。

- 普通面片颜色覆盖／发光材质与扭曲材质可由调用者通过 `CommonShaderParameters.VfxSoftDepth` 提供独立的单采样柔边深度视图，调用者负责其内容与生命周期；未提供时继续复制当前硬件深度。采样按绝对光栅位置除以实际颜色目标尺寸，再乘柔边深度图尺寸并向下取整、限制边界，不以局部视口尺寸代替整张目标。光栅遮挡继续使用原深度附件；贴花接收面及专用模型材质保持其完整深度副本，切图前刷新延迟绘制，不能把降采样柔边图当作接收面。旧兼容通道不自动生成游戏的独立降采样深度图；已准入原生透明通道按上文两级 MAX4 生成半尺寸硬件深度和四分之一尺寸柔边深度，显式独立柔边图仍须匹配该通道的实际尺寸。深度重建保留透视与正交约定；缺少对应深度时保留可见回退及诊断，恢复后清除旧提示。

- 使用 `mesh0` 至 `meshRender` 参数布局的 ScrollingMesh、OneShotMesh、BasicMesh、AnimatedUvSprite、BasicSprite、PremultiplyAnimated、SolidMesh、PrelitSprite 与 SoulPanning 专用材质，从绝对 `SV_Position.xy` 取得软深度像素坐标，按完整深度副本的实际尺寸向下取整、限制边界并读取；缩小或偏移视口不改用视口局部的 `screenUV` 采样整张深度图。这里只改变深度取样坐标，材质图案的 UV、滚动、透明度及各自屏幕抖动语义继续保留；完整官方样本的边缘、运动与出现消失仍须同条件实机验收。

- 普通预乘面片的 `ps_soft_edge` 在非专用材质、`scale_strength` 位于 `[0,1]` 且非负 `soft_factor` 可表示为有限半精度时，读取原生半精度参数与独立的粒子 XY 最小有符号尺度，计算尺寸相关的淡出厚度并保留 `0.001` 下限项。相同的无下限偏移只改变几何 clip Z，保留 clip XY/W；柔边视深度通过独立透视插值传递，不平移整张面片，不改照明世界坐标或照明尺寸。中心位于相机前方且偏移越过近裁面时按原生近面加 `0.001` 限制。非预乘、模型、专用材质与范围外参数继续原候选路径及诊断，不借此扩大材质支持。官方捕获的同输入对照只约束所测颜色分支，完整透明重建、动态随机序列及其他组合仍需独立验收。

- 普通面片来源的 `DEFERRED_DECAL` 与 `DEFERRED_DECAL_EMISSIVE` 使用三维粒子体积投影：保留三个尺寸轴和源旋转，从场景不透明深度重建接收点，按体积裁剪并读取原贴图及图集区域。平地相交与抬高离地、`vs_translation` 的 0/2 选项有 Terry 控制对照；该分支不把面片朝向选项重新应用到投影体积。独立 VFX 编辑器通过 `CommonShaderParameters.VfxGroundHeight` 明确提供挂点高度的水平接收面，仅在空背景处补足贴花显示并提示；超级视图明确提供网格的世界 Y=0 接收面，并在首个 Effect 着色前预写地面深度，避免地下粒子的显隐依赖实例提交顺序。共享节点默认不启用该能力；独立编辑器保留原有条件式地面深度。已有不透明表面不能被平面覆盖。零厚度体积不绘制。普通贴花保留候选覆盖合成；发光贴花另按随游戏提供的 `ps_main_deferred_decal_emissive` 和技术状态写入独立加法 RGB，保留线性辐射倍率 2500、预乘覆盖/纹理发光分离及最终透明度权重，不再用普通透明层压黑接收面，也不重复叠加普通面片的发光层。该倍率来自通道源码，不是整体曝光补偿；颜色空间与最终明暗处理仍未与游戏同步，不能把变亮或有像素视为完整外观验收。地形/模型接收层筛选、法线贴图对应的 G-buffer 接收面法线、贴花光照和任意变换保真仍未完成，持续保留候选诊断。
- 投影贴花的接收深度始终从完整场景深度副本按绝对光栅像素读取，向下取整并限制到实际深度尺寸；局部视口 UV 只用于接收点的 NDC／体积重建。深度不能按局部 UV 在整张目标中取样，否则缩小或偏移视口会错误裁剪贴花。普通与发光投影贴花共用该坐标合同，不使用普通面片的独立柔边深度图，也不改变原粒子参数。

- 普通 `DEFERRED_DECAL` 只绘制覆盖，不拆出预乘纹理中残余 RGB 的加法发光；透明 texel 的 RGB 不能成为矩形发光底图。其独立像素通道沿用原生 `ONE/INV_SRC_ALPHA` 合成结果：原始贴图／图集 Alpha 线性化后与粒子 Alpha 求旧覆盖，再执行可选 `ps_alpha_crush`、单独的预乘修正及 G-buffer 输出饱和，最后转换为当前后端的等价混合。粒子 RGBA 通过已有浮点自定义载荷传入，保留高亮非统一颜色及弱透明度，不先压成字节；`DEFERRED_DECAL_EMISSIVE` 仍沿用其独立通道。普通贴花另按原生接收面夹角计算 `u=min(abs(dot(normalize(projectorZ),receiverNormal))*2.5,1)`、`F=u*u*(3-2*u)`，剔除 `F<.1` 的投影，并在输出饱和前同时将 RGB 和 Alpha 乘 F。当前接收面法线来自重建世界位置的屏幕导数，水平接收面有精确控制；深度不连续处、法线贴图与原生 G-buffer 法线仍有差异，不能据此宣称完整延迟光照已还原。

### DISTORTION 与加权合成

- `DISTORTION` 使用独立折射材质，分别保留原 DXT5n 法线、diffuse 透明遮罩和可选渐变透明度；图集相邻帧混合之后再转换底图透明度，按原生顺序应用渐变、粒子透明度、裁切和软深度。空 diffuse 是合法的粒子透明度分支，不上传白色替代图；未设置 normal 时取粒子几何第三基轴的 XY，法线分支使用前两个基轴。粒子透明度大于 1 的值传到材质后处理，渐变 RGB、粒子 RGB 和 `additive_blend_mul` 不产生扭曲发光。三种输入均缺失的纯几何层仍单独诊断，不让其使同文件的有效层一起加载失败。

- 普通场景的显式合成作用域按“不透明 VFX 模型、普通颜色、全组加权方向、全组透射率、背景解析”的顺序处理全部实例；各实例内部保留对应通道的原相对顺序，源层之间夹有颜色层也不拆成多次折射。全组扭曲共用同一浮点加权方向及透射率目标，完成两遍累积后只解析一次背景；未进入作用域的独立 `Draw` 仍限本次调用内合成，不自动跨独立调用分组。保留原生方向长度、深度权重、分母下限和覆盖平方，浮点透射率直接累乘 `(1-A)`，不截断超过 1 的粒子覆盖；解析的 `(1-T)^2` 也不预先饱和，保留多粒子负透射因子的抵消。使用整张目标尺寸归一化屏幕坐标、线性 clamp 及累积缓冲的半像素采样偏移。零覆盖或零方向不写背景，解析仅写 RGB，保留场景原 Alpha，避免后置无贡献面片覆盖已有折射。无 normal 的普通面片通过现有自定义数据传递浮点第三几何轴，不经 Effekseer 的字节法线量化；原 DDS 法线解码不变。

- 扭曲法线的普通面片使用与固定面片渲染器相同的浮点切线／副切线，通过现有自定义数据传递其 XY，避免字节量化把零轴变成微小折射；模型仍使用原有基轴。摄像机朝向面片在反向投影且镜像局部顶点横轴时，同步反转法线横切线贡献；纵向法线和未设置 normal 的第三几何轴不套用此修正。扭曲软深度沿用“深度、软边与地形”的绝对位置与实际目标尺寸换算，不以局部视口坐标采样；按原始 `soft_factor * (1 + scale_strength * (saturate(min(scaleX, scaleY)) - 1)) + 0.001` 计算淡出厚度，保留有符号尺寸。是否启用与软因子分离，因子为 0 仍需真实深度；深度不可用时保留诊断。其他材质不因这个专用修复改变采样。

- 普通扭曲面片的着色基轴按完整粒子旋转乘对应约束／速度基轴传递，避免 X／Y 旋转在几何投影后丢失法线方向；竖直几何的世界竖轴不替代其着色逆视图。使用既有粒子四浮点字段，normal 分支传 T.xy／B.xy，无 normal 分支传 N.xyz／1，不经四元数或单位化丢失近乎平行视线时的基轴幅度。反向投影的横切线符号继续只在桥接处应用一次；未提供字段的旧调用仍按固定面片基轴回退。模型不借此扩展，任意速度与法线组合的原生视觉等价继续按各分支候选边界报告。

- 加权目标沿用场景深度、视口和多重采样设置并恢复 DX11 状态；同批／跨连续层、顺序、相反方向抵消、无贡献遮罩及场景 Alpha 有官方派生离屏检查。完整原版的部分硬折射过渡仍待同条件原生核对，不能把上述不变量或未修改源码的历史捕获当完整视觉验收。跨实例全局透明排序、复杂场景、任意方向／深度、非零视口及多重采样的原生视觉等价仍有验证边界，持续显示候选诊断。

### 天气、光照与显示输出

- 游戏光照的 `emissive` 与纹理自发光倍率保持独立。缺省及显式全／半分辨率透明通道、无扭曲普通面片的简单光照在纹理自发光倍率为 0 或使用预乘拆分、标量 `emissive` 为 1～10 时应用受限覆盖 RGB 倍率；纹理发光与透明度不随该倍率改变。其他光照仍保留候选诊断，模型、未准入的速度／水平朝向、UI 专用通道及未覆盖参数不套用普通摄像机朝向面片的天气材质。原生全／半分辨率绘制使用同一光照着色器及天气常量；光照处理与下述有条件的七矩透明累积相互独立，不能由其中一项推定全部材质组合已经还原。

- `GameWeatherStore` 保存用户从已加载资源中明确选择的只读 `.environment` 快照，包含来源路径和字节散列；不写回文件、设置或 VFX。该选择供所有 VFX 编辑器和超级视图 Effect 共用，经各场景的 `SceneRenderParametersStore`、`CommonShaderParameters.GameWeather` 进入同一原生绘制入口。清除选择后恢复原候选颜色；不会把通用模型灯光、程序生成的环境贴图或其强度单位当成游戏天气。当前读取自定义环境立方体、太阳方向/颜色/强度和 VFX 亮度；生成的环境立方体及额外辐照度重映射会拒绝并保留上次选择。该快照不自动追踪天气源文件的后续编辑，需重新选择。

- 普通面片天气材质优先读取原始 `ps_texture/normal`，兼容旧 `ps_normal/normal`；两处同时定义时报告歧义。在线性空间按 DXT5n A/G 通道加半量化步长后重建正 Z，按既有坐标约定翻转切线 XY，再通过粒子的旋转基变换到世界空间；图集帧分别解码后混合归一化，再按每粒子实际 U／V 翻转分别修正切线 X／Y；不能只翻纹理而保留原光照方向，也不能以四元数旋转代替单轴镜像。同层不同翻转符号按原透明顺序分批传入材质，保留完整着色四元数和粒子尺寸，不修改 ABI 或重排粒子；无翻转、无法线及未选择天气的原路径保持。天气立方体的 `left/right` 对应世界 `+X/-X`。普通摄像机朝向及受限 `vs_translation_velocity_v2`、`ParticleRelativeOrientation=1` 的朝向有原生法线控制；任意空间法线图、UV 90° 转角和镜像挂点尚未全部标定。未知编码会让受影响层恢复候选颜色并诊断；无法解码的资源只停用依赖它的层，模型任一备选或网格依赖失败时停用该层，其他层和原文档保留。

- 简单天气光照使用顶面环境光乘 `1-saturate(E)`，再加 `E*saturate(E)`；除既有摄像机面片外，已准入的摄像机朝向速度面片也读取显式天气的顶面光，该简单模式不依赖法线图，不借此放开速度面片的复杂法线光照。未选择天气时仍保留候选颜色及缺天气诊断，不把某个Terry场景的环境光硬设为程序默认值。同一输入的颜色对照必须显式配齐实际环境光，不能把天气条件不同的色差当作贴图或透明度错误。完整光照使用法线各轴平方加权的有符号环境面、自发光与太阳散射。太阳散射按原生粒子着色器和 GPU 常量重建：密度为 small+large，透射项为 `exp(-density*particleSize*averageSize*(1-dot(N,L))/2)`；视线与太阳夹角参与 Rayleigh / Henyey-Greenstein 相函数，按两类密度加权，再与透射项组合，乘原生辐射系数及太阳强度。零密度时太阳项为零，自发光仅抑制太阳项；预乘材质只照亮覆盖颜色，独立纹理发光不变。适用范围是缺省或全／半分辨率透明通道中的普通面片及上述已标定速度朝向；未准入组合的半分辨率重建、地形跟随、完整游戏透明合成和任意参数组合仍未还原，保留诊断，不以控制样本代表完整效果。

- 天气快照另保留 `tone_mapping` 的亮度、Burn、自动曝光开关及其目标，缺失值保持未知；自动曝光明确关闭且亮度在 `(0,100]`、Burn 在 `[0,1]` 时，手动值用于 8 位显示目标的最终色调输出，不改变粒子的线性 RGB 或透明度。其余情况使用亮度 1、Burn 0.05 的固定参考输出，并保留自动曝光、天气色彩查找表与完整场景分类泛光未同步的诊断；这组参考值不是对所有天气实际曝光的推断。`target_exposure` 属于自动曝光，不能在自动曝光关闭时解释为固定手动 EV；旧 `enabled` 字段也不作为已验证的后处理总开关。不透明色阶中的相对亮度等效不能直接外推到原始透明样本；透明背景的共同曝光与合成需分别验证。

- 天气 `post_processing` 仅在三通道 `contrast_r/g/b` 显式相同且不小于 1、RGB 亮度与饱和度均为 1、hue 为 0，且两张色彩查找表均为 `default` 时读取受控统一对比度；缺失值不猜成已校准参数。对比度按原生 `hdr_to_screen` 顺序在 gamma 后、默认查找表前应用 `C * (RGB - 0.5) + 0.5`，经共用 `EffekseerLighting.Display.W = C - 1` 传入着色器，默认 0 保持恒等变换，不修改粒子的线性颜色或透明度。已有场景背景在逆算辐射值前撤销同一对比度，未受 VFX 影响的像素保持原 RGBA；已经截断的明暗信息不能由逆变换恢复。小于 1 的对比度、非同值通道及其他未校准组合保留原天气与来源字节，使用候选色彩输出并提示限制，不能据此宣称完整天气调色已支持。

- 8 位场景的 VFX 泛光在浮点合成后、最终曝光前处理：按亮度阈值提取增量高亮，经过五级半分辨率下采样、各级横纵十一点模糊和逐级相加，再进入色调映射。原始场景背景的高亮贡献扣除，避免把已有模型和网格显示重新当成发光源；这仍无法恢复背景已截断的 HDR，也不等于全场景后处理。天气快照保留阈值与普通、粒子、自发光、水面四类倍率；只有四类倍率全部存在且相同时应用作者值，其余沿用阈值 4、强度 0.1 的受控参考，不把该参考解释为当前天气的真实分类强度。游戏 G-buffer 与透明粒子遮罩未共享，分类权重、已准入普通面片之外的 MBOIT 与完整游戏透明合成仍未重现；共享作用域中的跨实例折射与统一显示输出不消除这些边界。对照需核对实际 GPU 参数与内部渲染尺寸，不能仅凭源天气文件或经过系统 DPI 放大的截图推断采样尺度。

- 原生光照对照须固定方向、深度、画面位置和实际生效的明暗处理条件，并使用同位置的无光照等效输入排除共同位置明暗变化；跨位置色阶差和截断亮部不能用于拟合材质补偿。组合环境光、太阳光及中间自发光的静态常量法线对照支持受限响应，不能外推为完整天气、透明度或任意法线保真。普通窗口的场景颜色目标仍为 8 位，离屏线性浮点颜色不等于最终显示；不以重复纹理解码、统一调亮或单粒子倍率代替游戏最终色调与色彩输出。除受控固定曝光、统一对比度与默认色彩输出外，自动曝光、其余天气调色、完整场景分类泛光、雾、阴影和完整透明合成尚未重现，大于 1 的透明度锐化仍为候选截断。可读着色器只证明该源码分支，不能证明未公开处理函数的实现或游戏实际参数打包。

### 已知未完成范围

普通面片负值／超过 5 支持“朝向、自旋与角阻尼”所列的双实存等值常量，以及受限相同双表动态分支；其他原始通道布局、Bezier 角阻尼和新增复杂动态组合继续诊断。不能把模型分支的支持移植成普通面片已支持；普通恒定纯 Z 的旧 0～5 解析约定也不能称为原生计算着色器的精确离散更新。任何扩展都须重新核实上传、采样和步进，不能只去掉守卫。
