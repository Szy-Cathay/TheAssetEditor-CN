## 最终行为与边界

- 组件名称按现有 UTF-8 写入协议读取；RMV 名称字段固定为 32 字节，超限或包含空字符时拒绝保存，避免截断汉字。已覆盖编辑器保存、重开和 GLTF/GLB 导出往返；游戏和第三方工具兼容性不由这些测试保证。
- 固定与蒙皮包裹检查源顶点、有效权重和源/目标关系，传递相应动画播放器并支持撤销恢复。网格适配修正初始选区及参数回调，拒绝无效比例或矩阵，保留确认与取消的预览边界。
- 用户选定网格适配方案 A（参数在右）及重绑定双树方案。最终网格适配进一步统一三列正文和操作区对齐，两个分隔条可调且保留最小宽度，完整保留现有控件和绑定。
- 适合连续调整的数字框支持水平拖动，并保留键盘输入；名称、路径和 ID 不启用。超过拖动阈值后调值，支持精调、范围限制和取消，一次拖动形成一个合理的撤销步骤。
- Gizmo 与右上 XYZ 共同使用实际变换流程：显示本次总变换量，读回不再次应用；移动/旋转采用世界坐标，缩放保留 Gizmo 的基底与轴心，手势结束恢复默认数值。数字面板使用主题圆角，着色模式右侧分隔视觉已移除。
- 统一字号、浅灰斜体非加粗小标题与细线、输入文字左对齐、紧凑均匀间距和左框右文复选框继续保留。
